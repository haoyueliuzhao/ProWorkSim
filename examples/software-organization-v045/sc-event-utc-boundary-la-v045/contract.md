# UTC event date key

Maintain event_time.utc_date_key(timestamp). Return the ISO YYYY-MM-DD date after converting the instant to UTC, including day/month/year rollover. Inputs are exactly YYYY-MM-DDTHH:MM:SSZ or YYYY-MM-DDTHH:MM:SS+HH:MM/-HH:MM, with valid calendar dates, local years 2000..2099, hours 00..23, seconds/minutes 00..59, and offsets no greater than 14:00 in magnitude. No naive times, fractions, whitespace, bool or other types. Every invalid input raises ValueError("timestamp:invalid"). Preserve this API and error behavior. Use only the Python standard library. The application file and optional test_member.py are editable; public tests and this contract are read-only. A final delivery must be a fixed, publicly tested version. No communication, role division or recruitment is required. This is an authored event-interface maintenance fixture, not an upstream defect claim.
