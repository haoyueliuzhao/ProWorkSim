# Incremental event import and recovery

Maintain event_store.new_state(), apply_batch(state,batch), snapshot(state), and recovery.restore(checkpoint), replay(batches,checkpoint=None). new_state returns {events:{},totals:{}}. An event has exactly id, revision, account, amount: names match [A-Za-z][A-Za-z0-9_]{0,15}; revision is an int 0..1000; amount is an int -1000..1000; bool is never an int here. A batch is a list of <=8 events; the live store holds <=8 event IDs.

For each ID keep the highest accepted revision. Exact replay is a no-op; lower revisions are ignored after shape/type validation; equal revision with different content is a conflict. A higher revision replaces the old contribution, including its old account. Totals sum only current events; remove an account only when it has no current event (a zero sum with current events remains). Process each batch in given order, but reject the whole batch atomically: no partial state changes. apply_batch mutates the state only on success and returns None, never aliases caller batch objects. Errors are ValueError: batch:invalid_size; batch[i]:event_shape; batch[i].id/account:invalid_name; batch[i].revision/amount:integer_range; batch[i]:revision_conflict or :store_capacity.

Snapshot is {events:[events sorted by id],totals:{account:sum}} with independent copies. restore validates exact checkpoint shape, <=8 unique events, event bounds and exact integer totals; malformed checkpoint raises checkpoint:invalid; it neither changes the checkpoint nor forgets revisions. replay applies <=8 batches in order starting from empty or restored state (invalid batch list: batches:invalid_size). Restoring a valid snapshot and applying the remaining batches must match uninterrupted replay. Valid states come from these APIs. event_probe.py is a read-only public client exposing batch outcomes and state snapshots. Use standard library only. Production files and test_member.py are editable. Submit a current tested fixed patch; cooperation is optional. This is an authored event-interface fixture, not a historical product bug.
