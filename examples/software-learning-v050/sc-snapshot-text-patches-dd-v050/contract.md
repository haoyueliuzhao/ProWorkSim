# Snapshot-coordinate text patch batch

Maintain `textpatch.apply_batch(document, patches)`. `document` is a strict Python string of 0..4096 Unicode code points. `patches` is a list of 0..16 exact-key objects `{id, start, end, expected, replacement}`. IDs are unique ASCII strings matching `[a-z][a-z0-9_]{0,15}`. `start` and `end` are strict Python integers (not bool), with `0 <= start <= end <= len(document)`. Both text fields are strict strings; replacement length is at most 256 code points. No extra keys or other types are legal. Empty patches, empty document, and empty replacement text are legal. Never mutate the patches list or its nested objects.

All coordinates refer to the original document, measured in Unicode code points, not bytes. First validate all input shapes, types, bounds and unique IDs; any failure raises `ValueError("patch:invalid")`. Next require every `expected` to equal exactly `document[start:end]` from that original document; any mismatch raises `ValueError("patch:stale")`. Only after those checks reject geometric conflicts with `ValueError("patch:conflict")`: two nonempty intervals conflict when their interiors overlap; an insertion `[x,x)` conflicts with a nonempty `[a,b)` precisely when `a < x < b`. Adjacent nonempty intervals are legal. Insertions at either endpoint are legal, and multiple insertions at the same point are legal.

Apply the entire validated batch simultaneously against the original snapshot, independent of patches input order. A nonempty interval replaces its original substring. At each coordinate emit same-point insertions in ascending ID order, after any replacement ending there and before any replacement starting there. Unchanged original text stays exact; do not normalize Unicode or line endings. Return the resulting string. A deletion is a nonempty interval with empty replacement; insertions must have empty expected text. There are no partial results on failure.

Only textpatch.py and the optional test_member.py are editable. Use the Python standard library only. Deliver a fixed version that has passed the public tests for that same file tree. The team receives one shared goal with no predefined work roles; collaboration is not required for acceptance. This is a new controller-authored bounded text revision fixture for policy development, not an external benchmark, upstream bug, or derivative of the training task assets. All acceptance requirements are public here; private checks use different inputs under this same contract.
