# v0.11 实施与实验计划

日期：2026-09-24。依据[v0.10审计](reference/model-executable-audit.md)，起点e17e7e1d2c554994c14a569714d0c6e6e9e6456d。两主线并行，不等公开项目群完成才开展模型交互。

## 分工与阶段

1. 评价线：真实会话复现condition_specs规范字段work_item_id漏列；选中/无关/无条件三对照。新增EpisodeManifest和可读起止快照，固定经历区间、责任范围、提交与产物、场景/策略版本、终止原因；历史评价独立于当前世界。另加版本化RewardSpec，保留诊断并测试奖励投机边界。
2. 模型线：ModelPolicy薄适配，模型仅获自己的公开任务、观察、工具、真实结果和对话；记录每次HTTP attempt、实际请求/响应/usage及角色机会与世界动作对应。服务故障、格式错误、世界拒绝分别保留。先离线A0，再冻结A1协议并真实运行。
3. 执行项目线：固定官方jaffle_shop_duckdb源码版本和虚构种子数据，有限DuckDB工作能力真实运行SQL、查询和测试；代码/结果进入WorldCore版本。P0数据准备→P1经营指标/P2客户分析→P3核验，存在真实粒度协调与发布维护。程序可行链之后进行单模型执行角色试跑。
4. 根代理负责场景注册、CLI、第二推理服务、真实实验调度、交叉审查、归档与提交推送。

## A0与A1冻结口径

A0的模拟transport只证明协议。有效但业务错误的模型动作不重采样；多toolcall整次格式失败且保留全部原文；只允许预声明传输重试。模型不重写memory，由适配器追加真实对话；超上下文预算明确停止，不补造历史。每次决定最多一个实际动作。

A1计划六场景finance-direct、finance-route、report-direct、chain-before-submit、chain-pending、chain-accepted，各两个后端、三次独立新建世界，共36个开发episode。每场景只将一个执行角色替换为模型，其余同事策略固定。候选后端为官方DeepSeek Flash API和独立本地HTTP服务中的Qwen2.5-7B-Instruct固定权重。模型别名与实际返回标识分存；本地权重只读，保存文件身份，既有项目进程不变，记录共享GPU竞争。

执行前将精确参数存为JSON协议并提交冻结。预设每episode最多120次目标决策、150 HTTP attempts、500000累计token、单次输出8192 token、全世界500次机会；传输重试最多2次attempt。金额按已核实官方峰值单价保守预留，每个付费episode最多1 USD；主批18个付费episode上限18 USD。额外适配/公开项目/双模型协作pilot总上限6 USD，总上限24 USD；这一自行收窄上限不视为用户批准了更大的研究预算。实际账单未知时只报usage与价格估计，失败/不明usage保守占预算。若模型上下文或服务限制更紧，执行前明确写入协议，不执行后追加预算。

36个episode用于能力缺口、工具可用性、反馈与成本诊断，不是泛化测评；失败全保留，不通过换种子/追加预算/规则代做提高成绩。同世界后续成功不会回填旧episode。

## B线、奖励与训练门槛

先做固定公开仓库的一个四项目可行链，以及受控口径/粒度变化。SQL文字由工作人员编辑并实际执行，不能将预计算结果交给模型复制。执行范围仅当前项目可见输入、受限SQL/构建/测试，无宿主shell或网络。隐藏验证和控制区不进入工作能力；原仓库的虚构数据与新增研究组织流程分别说明。有限DuckDB执行不冒称完整dbt/生产CI。

RewardSpec必须通过空交付、改标签、重复发布、篡改测试、始终等待及历史回填攻击；未知/评价器故障无可训练奖励，真实可评工作失败不丢弃。奖励不给批准/消息/提交次数正激励。

144个公开项目主批与三组RL对照是后续规模建议，不作为本轮已执行预算。满足可行模型工作、可信历史评价、奖励校验及真实token/mask/行为概率后开展最小on-policy训练验证；缺少前提必须明确记录，不用旧SFT或商业API调用冒称RL，也不从文字伪造token或概率。训练发生与独立任务改善分别判断。

## 核验与记录

各模块先必要局部测试；正式冻结后一次全套pytest/Ruff和对应新实验。原v0.10及更早JSON不变；每项旧反例、开发失败、未执行项、服务失败、资源竞争分开归档。实验报告给出调用与训练分母、输入输出/缓存/失败成本、终止原因和未评范围，完成后自动提交并推送。

## 首冻结结果与第二冻结范围

首冻结9b9a4d8于UTC13:27–13:29完成36真实episode、另1个双模型episode、2个公开项目pilot及643项完整回归。条件7/7、历史边界14/14、公开项目机制58/58、奖励21/21、Ruff均通过。模型结果未按规则对照的通过率表述：36个均奖励0；DeepSeek2个制度completed仍因缺确切文件依赖而content_failure，11预算、5格式；Qwen18格式。所有公开端口捕获对照一致，服务usage无缺失。

真实API暴露sql_query未沿work adoption读共享确切版的问题：后续私有草稿使合法查询失败。局部补修并保留9b9原真实反例，不覆盖首批。另明确write_object现有依赖合同。

第二冻结只增加有记录的context_policy=latest_observation（完整原history不改，仅HTTP移除旧已登记观察）、声明start.roles和published起点、首决策RL接口。公开项目另3个诊断episode：相同真实P0前缀下static full/latest各一次，dynamic latest一次。它们不是原失败的续命或替换，也不是统计因果对照；P0仅按公开端口实际构建/提交/共享/发布，未运行目标模型，前缀成本与经历单列，episode从前缀后固定。原初始条件和预算结果保留。

各既有付费pilot已结束后未用预留释放；已记录峰值估计上界加这3个各1USD新上限仍小于原pilot6USD、整轮24USD上限。未知usage若存在须占用原预留，不能当0；实际首批无缺失。

首决策训练预选finance-direct-qwen-1/2/3，完整历史RewardSpec结果全0也保留。只对首个真实输出宏动作求梯度，后续行为固定，constant baseline0.5、LoRA q/v r8 alpha16 dropout0、AdamW1e-6一次更新；输入输出真实token/mask及现场采样logprobs需通过身份/概率核验。GPU前先停止本项目推理服务。该验证不是完整多轮Agentic RL或学习增益研究；三组对照尚未执行。

## 第四次冻结前的训练资源约束

原 teacher-forcing 尝试因概率不符停止，原 cached replay 尝试因 RSS 持续增长由主运行者终止，均未更新参数且保留原记录。v0.11.2 仅改 autograd 保存张量的存储：参数及其视图留在 GPU，激活移至非 pinned CPU，字节完全相同的重复 KV head 无损存储；不改前向数学、轨迹、概率阈值、损失或奖励。独立单组实际反向探测峰值 40.91 GiB、梯度有限且非零、0 更新。

最终完整三条轨迹尝试明确使用 `--max-rss-gib 128`，在此运行开始前冻结；继续共享 GPU 7、记录资源竞争。软件在保存/恢复 hook 边界检查 RSS，不是操作系统硬隔离。若本次再次触发限制，保留结果，不追加上限或筛选轨迹。成功才另做独立 adapter 接入环境试跑，后者不构成学习收益对照。
