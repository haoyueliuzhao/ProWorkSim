## 1. 三个分布不能再合并成一个隐式基线

对一个精确情境、稳定成员和冻结支持，数值接口区分：

- `base = b`：当前实际可重配支持的基础组成；用于物化权重 `q / b` 和权重盒。
- `history = h`：调用方显式提供并绑定到当前支持的历史训练组成，对应理论 `q_{j,t}`。
- `coverage = r`：冻结的正覆盖目标；不是当前自然发生概率，也不是已测效用。

每个分布必须在相同非空支持上严格为正、有限、归一化。零质量、缺失键、未知贡献、
负值或非有限值直接拒绝，不补小常数、不删除坐标、不将未知贡献写成 0。

`freeze_history_anchor` 将历史分布与当前 `window_id / situation_id / member_id`、
坐标系统、来源窗口、来源配置 SHA256、事前转移规则和初始化类型一起固定。
`solve_*` 必须再次传入当前绑定，接口检查与该历史完全一致。
`declared_initial_configuration` 必须明确指向当前窗口；
`transported_previous_configuration` 必须指向另一个来源窗口。首次 `h=b` 可以是事前声明的初始化，
但不会默认发生，也不会被描述成已经继承了跨窗口历史。

历史转移本身尚未实现。传入的 `h` 必须已经落到当前支持，并处于本轮 `q/b` 盒内。
若不满足则停止数值选择，要求在未来运行协议中明确支持变化与转移；本模块不默默投影、
平滑或重新归一化。配置摘要绑定声明，不足以证明声明所引用的历史运行真的发生过；
后续运行器仍须核验来源回执和转移过程。原始轨迹坐标跨窗口改变时，这一点尤其重要。

## 2. 可见理论的一阶目标

新规则固定：

\[
N_a=[\log(r_a/h_a)]_+,\qquad S_a=\widehat C_a+\beta N_a.
\]

\[
\max_q\quad \sum_a q_a S_a
-\lambda_h D_{KL}(q\Vert h)-\lambda_r D_{KL}(q\Vert r).
\]

\[
\sum_a q_a=1,\quad \ell b_a\le q_a\le u b_a,\quad
\operatorname{TV}(q,h)\le\rho.
\]

这里两项 KL 系数均严格为正，`beta >= 0`；支持不会由锚创造。
本模块将可选 TV 信赖域明确冻结在历史 `h` 周围，与 `q/b` 权重盒分开。
本地 §7.3 只规定可选小步信赖域，§11.3 的局部坐标围绕 `Q_t`；
因此“TV 中心为 h”是此次明确记录的实现选择，不能反向写入旧实验。
旧模块的 TV 中心仍为 b。返回值分别给出 `tv` 和仅供说明的 `tv_from_base_diagnostic`。

仅单纯形约束时，解为：

\[
q_a\propto h_a^{\lambda_h/(\lambda_h+\lambda_r)}
r_a^{\lambda_r/(\lambda_h+\lambda_r)}
\exp\left(S_a/(\lambda_h+\lambda_r)\right).
\]

盒或 TV 激活时，用归一化乘子和非负 TV 乘子的嵌套二分求约束解。
逐坐标在 log 空间计算，防止通常尺度下直接指数溢出；无法表示的数值尺度会拒绝。
最终只向可行历史收缩约 `1e-12` 并修正浮点归一化残差，再检查约束，
并非先随意剪裁后重新归一化。TV 半径 0 返回显式历史；此退化情况不估计 TV 对偶乘子。

默认 CPU 参数为 `lower=0.5, upper=2.0, tv_limit=0.2, lambda_h=1, lambda_r=1, beta=0.25`。
这些是机制控制默认值，不是对真实软件模型贡献单位校准后的最优参数。
所有输出 `effectiveness_evidence=False, contribution_estimation_executed=False, training_updates=0`。
输入 `C` 是已给定的一阶数值；本模块不把传入一个数字当作已经执行了更新后开发工作。

## 3. 三种方法的输入与坐标不同

| 接口 | 配置坐标 | 专用语义类别输入 | 覆盖目标 | 类内权重 |
|---|---|---|---|---|
| `solve_g_raw` | 原始成员轨迹 | 无；接口不接收类别或图 | 默认原始轨迹均匀，或事前声明的非语义目标 | 每条独立 |
| `solve_g_lift` | 原始成员轨迹 | 显式接收轨迹到类别映射 | 支持类别目标按冻结类内基础比例展开 | 每条独立 |
| `solve_i_p` | 稳定成员的工作类别 | 显式类别坐标 | 冻结正类别目标 | 同类共享 `q_z/b_z` |

G-raw 的接口不读取 Mapper 类别、工作图或语义支持对象，其历史坐标也必须是原始成员轨迹。
默认 `r_s=1/n`。显式非均匀目标必须使用 `predeclared_nonsemantic` 标签；
该标签不能证明调用方私下没有根据类别构造它，因此后续协议和输入来源审查仍然必要。
均匀原始基础与均匀原始覆盖下，G-raw 的 N 可以为 0；这是事前先验的结果，
不是必须给一般基线施加类别不足度。贡献仍然可以使不同原始轨迹具有不同权重。

G-lift 是读取类别先验的**辅助对照**，不再冒用完全一般的 G-raw 名称。
原始基础可非均匀，类别 `z` 的基础质量 `B_z=sum_{s:z(s)=z} b_s`，展开为：

\[
r_s=r_z\,b_s/B_z.
\]

G-lift 仍在原始轨迹坐标计算 `N_s=[log(r_s/h_s)]_+`，并独立优化每条权重。
如果实际历史类内比例与当前基础不同，N 也可以在类内不同；模块不会为追求形式一致而重置历史。
在历史按相同类内基础比例展开且贡献类内相同的控制情形中，G-lift 与 I-P 的逐槽权重、
两项 KL、TV 和目标相同。测试覆盖这个等价特例，并同时验证一般情况下 G-lift 可以产生类内差异。

I-P 只做成员条件化的类别共享一阶优化，`materialize_class_weights` 仅进行坐标展开。
没有图网络、I-S 结构共享、跨成员联合项或跨窗口贡献预测器。该展开函数也不检查奖励可信度、
真实生成动作和原始 token，不能作为训练准入凭证。

## 4. 此次检查及未执行内容

本次 14 项 CPU 测试全部通过，涵盖：

1. 非退化 simplex 解与独立闭式计算相同，且 h 与 b 不同。
2. 单坐标、零 TV 半径和固定权重盒的退化解。
3. 对数 N 使用历史，不使用当前 b 替代。
4. 紧盒与历史 TV 下，数值解优于检查过的独立可行网格；另一例实际激活 TV 边界。
5. 历史摘要修改、窗口错绑、支持变化、盒外历史和坐标系统错用均被拒绝。
6. 非正/非有限支持、未知 C、非正锚系数均被拒绝。
7. G-raw 无类别/图参数；G-lift 与 I-P 的先验和类内权重差别明确。
8. 在声明的等价特例中，G-lift 与 I-P 目标和逐槽权重一致。

这批合成数据只是函数输入，不能计为策略采集、试训反馈或算法收益。
此次没有执行贡献试训、正式参数更新、独立确认，也没有将新函数接入旧 v0.29 runner。
未来模型选型完成后，仍须冻结支持、历史转移、贡献探测或可扩展一般元优化、成本预算，
并完成原始动作绑定，才具备运行同模型 B / G-raw / I-P 比较的条件。
