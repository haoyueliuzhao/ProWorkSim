依据[本轮审计](reference/audit-v020-next-v021.md)，保留v0.20 P0的有限结论及两个P1失败。旧P1按原合同已经结束，其未开始世界不补跑、不回填；没有“测得零学习收益”，而是当时没有进入学习与业务评价。

执行结果已另行闭合，见[完整报告](experiments/domain-v021.md)：本页保留事前合同，N/E于GPU4实际完成，共0.338576 GPU小时；未启动后继学习。

本轮分N、E、D三线，结论和费用分别记录。N/E使用新授权预算，不使用旧P1剩余额度；D为CPU来源、合同与评分入口准入。

## 1. 新授权和资源安排

在助手明确提出N≤20分钟、E≤40分钟、总计≤1 GPU小时的单卡方案后，用户回复另一项目预计凌晨释放显卡，并允许自主选择最先释放的一张。按此执行[固定N/E配置](../examples/id-vtdo-v21/ne-approved.json)：

- 等待物理GPU0–7中首张符合条件的A100 80GiB：无计算进程、free≥78000MiB、利用率≤5%。不依据“尚有40GiB”提前与另一项目抢占；不暂停或终止其他项目。
- 一次只运行一个模型进程，N结束并释放后才加载E；绑定第一次选中的物理卡，E等待同卡再次空闲。多个卡同时被观察为空闲时按编号确定，不声称知道未观测到的精确释放时刻。
- 新预算：N最多1200设备秒，E最多2400设备秒，总计最多3600；单任务最多900秒。E上限还要扣除N实际已用时间，不能把N未花完的时间扩充到超过40分钟。
- host RSS≤64GiB，N/E总产物≤5GiB，本进程GPU离散用量上限72GiB；原始权重和既有数据不重复计入产物。模型API费用与参数更新均为0。
- 时间停止保留30秒余量，覆盖轮询、资源查询和自身子进程终止；报告实际耗时，不冒称硬实时分配器。只给本次独立子进程组发终止信号。
- 等待本身不计设备时间；每线只有一次启动意图。进程崩溃、数值异常或业务失败不自动重启，不形成“还有时间就继续试配置”的队列。全局资源/源/身份记录问题可使监督停止。

N和E均沿用已有v0.20.1（9B、BF16主干＋FP32 head/LoRA/归约、单常驻、无prefix副本），不是第三个精度组合。P2、外部伙伴或judge、参数训练和第三配置不在自动执行范围。

## 2. 四种资格分开

| 项目 | 判断对象 | 本轮关系 |
|---|---|---|
| 推理执行资格 | 实际原生调用、模型身份、原始token、权限和真实工具后果 | E必须满足 |
| 学习概率资格 | 实际采样s与选定学习路径p_t的对应 | N诊断；原门不改，不是E入口条件 |
| 反向容量资格 | 依赖完整的可微图、真实backward和资源 | 本轮N仅梯度前向，不冒称通过 |
| 工作表现 | 固定版本独立交付、复核、修复与断点 | 新E6实际测量，零更新 |

N出现概率差、模型非零退出或单线耗时不足，不自动阻断E。共同资源已经耗尽、配置/源无法确认、监督不能安全控制进程等问题则不同，不能为完成E突破这些边界。

## 3. N：对已保存序列作定向数值诊断

固定原v0.20.1的8473输入＋146输出，实际actor参数、完整profile、call/numeric SHA均绑定。原采样概率s只读；不重新采样，不裁尾，不改mask来挑容易token。

比较cache增量teacher replay、完整无cache/no-grad、原训练模式的完整grad-enabled前向。记录实际卷积/DeltaNet参考函数进入、mask/position/cache dtype和shape，预声明位置0/1/2/31/73/145的少量hidden/logit摘要，原失效位置62另标为事后诊断。旁路摘要可以detach，其结果不喂回模型；过去缓存不detach后伪称训练图完整。

当前安装版cache有原地写、checkpoint层会关闭不支持的有状态cache路径，所以本轮不贸然进行cached-grad或backward。full-grad记录train模式、非重入checkpoint、dropout、requires_grad与grad_fn；这只验证前向图的实际状态，不等于完成反向。

若cache重放不对应原s，先排查记录、位置、状态和重演约定；若cache对应而full不对应，则聚焦观察到的增量/整段差异。不能从进入某函数就直接判其是唯一误差根源。最多后续选择一个有证据的实现，须另冻具体改变及未参与选择的验证请求，本队列不自动执行候选搜索。[具体实现和CPU控制](experiments/numeric-paths-v021-preparation.md)

## 6. 数值问题与基础优化理论边界

区分实际采样s、更新前学习路径p_t、更新时p_theta。原门只检查已采样token的log p_t−log s；它不是全分布KL、梯度无偏、业务效用或PPO clipping的定义。现有PPO与原概率门保持，不将重算概率偷偷替换原行为概率。

优先路线仍为足够一致、保留过去LoRA依赖且可承担的计算实现。若以后选择显式mismatch处理，应另冻基础配方，分别处理c=p_t/s与r=p_theta/p_t；代数c*r=p_theta/s不能证明带clip/mask/截断的目标等价。token校正也不自动校正整个联合轨迹状态分布。c/r与ID-VTDO组成q/b分开，所有方法共享相同基础修订，可信失败保留，不自动换GRPO。
