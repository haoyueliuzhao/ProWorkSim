# v0.15：候选模型选型与真实来源上的闭合在线学习

本轮依据[v0.14审计及模型建议](reference/learning-audit-v014-model-selection.md)。v0.14原学习比较永久保持未完成，不补满旧744槽，不把缺少训练后测量写成零收益。本轮新来源、新模型/模板和新运行身份独立记录。

## 并行工作与责任

1. 模型线：核实官方后训练检查点，适配原生工具格式与模式，进行有界开发筛选；选择后所有岗位共用同一actor/LoRA/optimizer，不混用岗位模型。
2. 数据线：UCI Online Retail原XLSX、字段说明和CC BY归属，按完整发票实体构造可查询有限片段，公开新的模拟报告政策；CPU规则只证明可行，不作为actor训练标签。
3. 软件线：固定Marshmallow源码与MIT许可、一个有意义的字段/消费者兼容需求；模型真实读、改、测和提交。隔离必须实际阻断宿主其他文件/网络/进程访问，普通cwd不算隔离。Click仅在原资产不可运行时作为另登记替代。

真实来源接入不等待构造SQL显著收益；模型选型不由历史7B绑定。暂不扩展大型通用平台，也不要求四项目全自主成功才训练。首个实际UCI训练合同可在单岗位、双成员与三成员责任上完成；没有实际跨项目消费就不声称四项目交叉已建成。

## S0：模型可用性与原生接口

优先候选为官方Qwen3.8-27B、Qwen3.5-9B；Qwen2.5-7B-Instruct保留同条件历史模型参照。Qwen3-32B只作事前登记的架构集成备选，替换需要记录哪个明确技术条件不成立，不按业务成绩临时更换候选。

两新候选已核实为qwen3_5混合Gated DeltaNet/Gated Attention，不能套旧GQA attention补丁。独立环境固定实际Torch/Transformers/PEFT版本及依赖，不修改历史训练环境。原生模板采用non-thinking，温度0.7、top_p1/top_k0、无重复惩罚/约束采样，输出2048、完整上下文16384。此采样分布是本实验的冻结选择，非默认照抄模型卡推荐；实际模板、参数解析、数值profile和所有own tokens均保存。

9B先测FP32 highest单卡；27B优先同FP32 highest显式多卡放置，禁止静默CPU/disk offload。仅当显式集成不可行才另登记BF16能力条件，不能把它当FP32可训练起点的同一能力证据。LoRA仍r8/alpha16/dropout0、q_proj/v_proj；混合模型仅匹配full-attention投影，必须记录实际模块和参数量。完整官方checkpoint文件及revision/SHA固定；text-only使用不得留下随机初始化语言参数，未使用视觉/MTP模块明确记录。

只做短的公开工具格式校准和必要forward/backward兼容性检查。所有失败保留；不知道工具格式如何使用的失败属于接口/集成成本，不直接断言模型业务能力差。下载可以通过官方镜像，但文件须与固定官方revision的SHA逐一匹配，不换权重或量化。

## S1：预定开发能力筛选

计划12个UCI开发情境（3个不同实体事实×实现/复核/双成员/三成员链），每个3次独立采样，3模型共108个episode。全部属于开发用途，不用于正式泛化结论。相同原始业务情境、role任务、权限、真实工具、期限和采样seed，模型按各自官方模板；没有模型专属答案、后台采用或SQL修复。不同native tokenizer下实际token数量不同，均记录而不冒充相同计算。

原生非thinking/输出2048/上下文16384在接口校准后作为正式profile冻结，不在失败后临时加思考或预算。同一运行固定当前actor，不训练。筛选结果主要排序：

- 实现独立正确build与固定提交、复核固定成果及独立依据判断，分别按事实与重复次数展示；主指标为这两类完整责任的完成计数。
- 再看双成员/三成员完整成果、具体错误恢复和按实际设备数计的资源代价。单纯读取/交接奖励不替代这些指标。
- 优先选择在多于一个事实、多个运行中显示基础实现/复核能力且可以执行相同检查点训练的候选。若两候选主计数相同，依次比较团队完整成果和实际成本；不以“出现一次成功”作充分能力结论。

主指标未出现差异时也保存负结果，可选集成可行且成本可承受的最强观测候选继续有限基础RL；这是初始化选择，不把可信失败排除出训练。不使用这些开发结果宣称学习收益，未运行条件保留缺失，不补成0。

## N0：在计划窗口规模上桥接

选定候选与数值profile后，另从fresh base/LoRA起点执行两个固定16例窗口（4责任各一个ξ×4次，事实f0/f1），共32条新交互。第二窗必须由第一窗更新后的策略产生。使用原max0.02/mean0.002概率工程门；不删异常token、不覆盖行为概率、不重采到通过。

本项验证当前规模和更新后策略的可运行性、内存/时长/保存恢复；不要求业务成功。它不是新的“完成两次更新即研究通过”阶段，N1训练后评价仍为主要交付。容量权重不进入正式初始模型。诊断选择与预算写入协议，避免为完整梯度统计耗尽评价预算。

## N1/N2：新UCI来源上的小型闭合比较

本轮将建议的有限MC/RTG pilot直接放在已冻结UCI责任族上，同时完成真实来源实际在线学习；不重复一套构造SQL大研究。它与v0.14旧家族实验、筛选成绩、软件资产试跑分别报告。

预案：2条件×1训练seed×4在线窗×16例=128训练episode。每窗四责任各1/4、每ξ重复4，事实f0/f1/f2/f0固定轮换。共同初始开发8＋锁定12=20例；两条件第2窗后开发各8=16；两条件第4窗后锁定各12=24，评价共60，总188例。N0实际容量后、N1首次采样前固定精确运行资源和协议；必须为全部60评价保留预算，不能用旧7B耗时直接承诺新候选成本。

共同初态包括actor/critic/两个optimizer，按实际张量指纹核对；初始评价可以共用但不能重复计样本。MC与joint RTG仅改变同一终局合同的时间信用。窗口内固定θ、结束后一次共享更新、下窗真实新采样；不用SFT或固定轨迹反复优化充当在线窗。失败仍进入基础RL，未知和概率停止单列。评价不更改学习态并恢复RNG，不选最佳checkpoint，不因为没有改善追加训练。

单seed只能给pilot结果；不选幸运seed冒充三seed，也不与旧六个失败run拼成复现实验。若预定节点都完成，无论正负均结束；若仍发生数值/环境不可执行条件，准确记录未执行项并只处理有证据的主阻断，不放宽门或无界重跑。

## 方法支持、来源与成本

同一窗口/θ/Γ/ξ统计真实方法类、自身动作、有效性和b；M4仅使两类各2成为可能，不保证自由度。没有当前多方法支持就保持Q=B；不跨模型、窗口或布局拼接，不按提示强制类别，不凑齐成功才更新。达到条件后另冻同起点配置试训、真实开发评价与正式更新，不因新增真实来源自动宣称ID-VTDO增益。

UCI train/development/locked按客户及完整发票关联拆分，所有派生任务保留来源用途；这些仍是同来源保留，不是独立来源泛化。Marshmallow是另一工作/来源资产，本轮若用于选型或开发也不能同时称未见独立测试。公开素材可能曾被预训练见过，不能保证无污染。真实字段与源码、模拟需求和组织过程各自标明。

资源逐PID和设备记录，区分进程小时、实际使用设备数×占用时长、并行墙钟及采样token；多卡27B不能按单进程小时伪装与单卡9B同成本。当前8张A10080GB可用，保留其他项目竞争记录，不停止外部作业。大依赖/权重临时目录置项目数据盘；密钥不进入提交。仅必要定向检查，完成后自动提交推送。
