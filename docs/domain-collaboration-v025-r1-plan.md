## 2. 监控的必要修订

入场仍须完整成功的GPU资源快照。运行后只查询所用物理GPU（索引与UUID绑定），每条nvidia-smi查询最多5秒；避免其他显卡的查询故障直接中止本模型。

单次失败完整记录并进入有界宽限，连续120秒不能取得完整遥测才停止；计时从首次失败查询发起时开始。重新获得完整新鲜样本才清空连续失败计时。未知显存是None，不写0；旧成功样本仅作带过期标记的参考。新鲜测量确认实际超限立即停止，不能用宽限遮蔽真实显存/RSS/时限/产物越界。若只得到本worker新鲜单行测量，它作为已观察下界；其他行坏掉不能掩盖这个下界已越限的事实。

原进程直接由新监督器持有Popen并回收真实退出码，不采用运行中SIGSTOP交接。查询前后都检查进程退出，避免把正常退出时的遥测缺失误认成模型丢失。worker启动ticks及GPU UUID变化独立处理；只终止本次生成的worker进程组，不操作其他项目。
