## 现金与Token账

独立账本不打开旧v175账户用于扣款，也不转用其8.29元余额。总新准入额度300元；先为12个尚未开始的重复回合各预留10元，共120元。主测新准入不能使用这部分余额；某重复回合进入时，替换为实际在途占用，结束后释放未用估计。每回合常规启动预约为5元，实际费用和Token始终按供应商usage记录。

这些预约基于历史成本，是调度保障措施，不是理论最坏费用覆盖。每回合5M在冻结最高费率下可达40元，300元不可能保证所有60回合均达到最大消耗。遵循用户已确认规则：现金只控制新回合准入，已开始回合继续完成，尾部费用可能越过准入线；不偷偷增加新额度。若仍不足，未开始身份原样保留，不缩减5M、不按中期分数换题，也不将未启动算失败。

费用为冻结峰值费率计算的上界，并非供应商发票。记录实际输入、输出、缓存命中与未命中；缓存是输入子集。摘要费、物理重试、技术异常费均保留；关键卡片及恢复内容在后续输入中只计一次，不另外重复加到总账。

## 准入与异常处理

先完成规则与来源CPU控制、固定48点离线回放、真实SDK脚本控制、公共短页头和原文完整性控制。4个零模型Docker诊断及12题gold／empty资格核对之后，才派发相应任务的API。没有新的模型成绩前冻结源码、规则、题单和接口修订。

使用同一资源分配锁读取容量租约，避免评分清理与枚举之间的FileNotFoundError。评分准备异常独立入队，不把正常生成改写为模型中断；账本和候选先保存。单题模型或评分异常保留原件及费用，不自动重采整个已调用回合。无法证明私有资源清理时停止新准入，并让已经进入的工作排空。公共API或服务故障另行记录，不能填成正常代码失败。
