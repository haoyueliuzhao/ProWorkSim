# v142：40题三条件试跑的启动说明

本批比较 **S1一人、FREE2双人自主分工、REVIEW2开发与独立复核双人**。三组都在新版ProWorkSim受管OpenHands环境执行；不是再做REF与PROJECT比较。研究路线、实现依据和分析口径见[v141总方案](software-benchmark-v141-roadmap-and-p0.md)。

## 已固定的实验身份

同40题、12仓库、3条件，共120个新的首次尝试，全部清单及seed在[pilot panel](../../artifacts/software-benchmark-v142/pilot-design-r1/panel.json)。每队5M输入＋输出，不按人数翻倍。DeepSeek Flash非思考，131072上下文／98304输入／32768输出；全批6亿token是上界。官方评分器和任务初态不因组织改变。

**用户新增API预算为合计400元。** 三条件使用同一个新SQLite账本，成员／组用量另行归属；旧账本不打开、不增加额度。正式请求由宿主直连官方HTTPS，模型不获得互联网搜索／fetch工具或宿主网络入口。依赖准备仅四个小型wheel从清华镜像直连下载，约130KB；没有安装到共享主机。

API预算已获批准；本说明和源码封存不创建Docker运行授权。新root等效对象范围须依据用户的“未经授权严禁使用root权限的相关操作”获得明确批准。具体审阅对象为[runtime proposal](../../artifacts/software-benchmark-v142/runtime-authorization-r1/proposal.json)。

## 资源范围

最多16对生成容器、4路环境启动、2路异步评分。单生成对为actor 4CPU／16GiB和controller 2CPU／32GiB；评分容器各4CPU／16GiB，宿主评分进程各4GiB并共享其评分CPU。唯一普通用户协调服务8CPU／32GiB、高水位30GiB；总许可上界112CPU、840GiB，实际准入还保留宿主CPU、内存和磁盘余量。

本批最多568个容器、124个专用卷：含120个团队的生成、代码及可能不同版本的交付评分，4个零模型诊断对，以及最多80个环境控制名额。环境控制是上限，**不要求重新测试全部40个已知环境**：35题已有窄等价证明；4道Requests和pytest10081因具体修订需要新资格。不存在新系统slice、GPU、宿主绑定、端口监听、共享挂载／网络／驱动修改或旧服务重启。

容器默认`network=none`、drop ALL。只有4道Requests评分容器使用既定容器内网络能力；其中两道TLS任务经冻结的httpbin.org公网地址80／443受限通道访问，最多16个session、8192连接、1024MiB应用载荷，严格保留TLS和主机名校验、明确使用已记录的评分CA修订。另有一次最多4连接／64KiB的直连端点探测。能力仅在新评分容器，不能改宿主网络。

## 启动与停止规则

1. 冻结当前代码、执行计划、实际工具声明、离线运行包、依赖及CPU证据；具体Docker范围批准后才进入外部动作。
2. 一次受限当前端点核验。失败保留两道TLS任务未定，不用旧IP冒充当前可用，也不阻塞其他独立题。
3. 冷评分准备：复用35题相同评分环境的证据，记录其余新控制需求，不把配置准备称为控制通过。
4. 新普通用户服务内执行S1／FREE2／REVIEW2三个真实零模型诊断和一个代表性大仓库初始化诊断，记录controller实际峰值；完成必要的新gold／empty控制。
5. 首次正式响应负责各条件真实路由准入，随后公平扩展至资源允许的16个团队；不额外调用中性模型测试，生成与评分独立排队。
6. 结束保留题目、补丁、双端点评分、费用和侧录，只清理本批精确归属且停止写入的对象，释放本轮普通用户协调资源。

局部环境、生成或评分未知独立封存；已调用回合不自动重采。共同账单、候选身份或资源清理完整性故障暂停新派发，保留在途收口证据。现金不足停止新准入并按实际余额决定已有请求是否可继续，所有历史费用与不确定预约保留，不退款式抹除。

## 交付报告

每组计划分母40，同时列实际启动、闭合、有效评分、代码通过和合法交付，通过率不删除现金中断或技术未知。完整结果未定则报下界与未知范围。列每队实际平均输入、输出、合计token、中位数与分位数，成员及摘要费用、缓存命中／未命中；每个均值说明用量完整性和分母。

协作分析按同题配对和仓库分层：FREE2与S1比较增加伙伴后的整体变化，REVIEW2与FREE2比较相同人数下固定复核组织的变化。结合消息真实呈现、重复阅读、返修次数、伙伴代码采用、最终闭合与剩余预算解释；消息数和工具数本身不等于净通信成本。仅40题工程试跑，不宣称总体最优组织或训练收益。

本批没有开启通信压缩、角色RSI、SEARCH或后续独立确认集；这些阶段需在本次机制和数据可靠后分别冻结。
