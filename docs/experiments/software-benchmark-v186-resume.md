## 已定位的阻塞

1. **磁盘门槛没有接到实际入口。** 当前方案规定保留128 GiB并按每对4 GiB预约临时空间，但实际 `_run → wait_capacity → capacity` 仍使用旧版固定256 GiB。可用空间降到约216 GiB后，四项任务停在容器预约之前。新入口直接使用同一原子资源预约规则：128 GiB，加已有临时空间预约及下一对4 GiB；内存、CPU余量和四对／两评分上限保留。资源等待会报告具体原因，不再把等待线程数当成实际运行并发。
2. **跨队列现金预约误算。** 旧实现用当前队列的题单判断每题采用5元启动预约还是40元理论上界。Pylint队列只含四题，因而把其他组的四个在途任务算成160元预约，曾在实际累计92.06元时错误停止。新实现按共同实验的job类型识别5元启动预约，与查询者的题单无关；其他实验的独立预约规则保持原样。
