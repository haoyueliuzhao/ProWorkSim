审计要求的旧staff_done测量窄修已完成：原v043 PT的work-use null在完整原call/窗口/控制/退休关联成立后，另存修订为false，原字段和R不改。它修的是工作链来源关联；本次新暴露的是反馈终止原因分类，二者不能混为“已有补丁其实未执行”。

后继应优先单独修复这一分类，保留来源不明/未commit/身份或窗口冲突/多个退休候选/退休后继续生成/管理员或系统停止等反例。无需为该测量遗漏继续缩页、改Γ、换模型或重采已经完成的四条；任何恢复原未启动库存的安排都需明确记录恢复范围与机制证据，不能回写本轮为完整16槽或抹掉原false。
