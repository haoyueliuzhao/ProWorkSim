原10题的gold／empty环境证据经严格同环境核验复用；Pylint-4661的原参考补丁实际已应用，失败源于其新增appdirs缺少离线安装来源，评分侧增加验证过的本地wheel后，gold通过、empty失败。Requests-2317的旧`Session.send()`绕过环境变量中的CA路径，曾使一项PASS_TO_PASS失败。r3评分修订仅在原CA路径与哈希都匹配时，将SSL加载映射到“原根证书＋容器私有CA”，保留原生TLS及主机名验证，不改原CA文件、源码、补丁或测试。私有httpbin及两个逻辑域名都留在network=none容器内，没有宿主端口或公网流量。新gold通过、empty失败，两个控制容器均已清理。因此12题环境已合格；这是明确记录的评分环境适配，不能称完全未适配的原生网络环境。

## 首个真实回合的测量问题与后续处置

Django-11095已正常闭合，独立host用量完整，90个原始请求及响应与实际usage一致；其r2分析仍标PARTIAL，缺85个request→decision关联，工具回执也未完整匹配。该问题不是API调用失败：实际归档器把`managed-runtime/experience.jsonl`保留在`controller-output.tar.zst`，没有在导出目录展开，而r2分析器只检查展开路径。不能据此将原轨迹说成丢失，也不能在核验归档原件前直接升级COMPLETE。

独立r4离线分析器已经完成：先验证原传输回执、压缩档和完整解压流SHA，再流式读取真实experience记录。Django的85个Agent决策关联、另5个摘要请求、86次执行机会与工具回执全部对账，九个完整性维度均为COMPLETE。7项定向CPU测试覆盖归档缺失、重复成员、响应身份错误、压缩内容变化、解压流SHA变化和控制器错绑。原r2分析结果、工程门和活动源码全部保留，没有补造事件或重采模型。第二个首题Matplotlib也已正常闭合：92请求、88个Agent决策及89次执行机会与回执全部匹配，九维COMPLETE。两题合计182次物理请求全部结算，实际9,913,680输入＋输出Token，按冻结峰值费率计费上界17.28972072元，未定预约0。前任异步评分与资源释放完成后，新部署承接其余10个尚未调用的原身份，仍共享原150元账本。

Requests的r3叶waiter只等待父工程门，没有创建生成环境或调用模型，已在父队列结束后自行结案并释放资源。其早期`CA_qualified=false`是在父门未出现时短路尚未评估，不覆盖独立CA控制已经通过的事实。Requests原身份已与其他九题统一纳入r4首次调用队列，没有增加第13题或额外重采。

元数据勘误：r2／r3协调器中的`old_ledgers_opened=false`沿用模板字段，不能理解为未打开本轮原账本。实际初始化和所有请求均使用同一个r1账本；正确含义是没有使用其他实验的旧预算。冻结源码不为这项说明热改。

首个Django回合的控制器观测包围计时：433次边界调用，累计CPU约0.851秒、墙钟约0.891秒，观测错误0；旁路目录约17.80MiB。整控制器峰值RSS约1.14GiB，不是观测器独占内存或相对于关闭观测的内存增量。这些计时也不包含host端HTTP原件捕获与离线归档解析的全部成本，因此不能把0.891秒说成完整观测系统的总额外延迟。该题离线归档核验与重建约5.65秒，解压验证约1.44GB原流，临时只保留所需轨迹，不展开完整世界。

新接续r4的必要控制已通过：scope／身份／账目与门10项、调度1项；评分路由与清理控制通过，四个任务、运行时、依赖、CA语义篡改负例均拒绝，10份环境资格严格复用成功，新增环境控制0。续跑产物明确标记“本文件仅10题、原实验分母12”，不能把原两题从最终分析中删掉。代码审阅与测试均未读取官方分数作为准入条件。
