- **LA r1：** 两成员各7次实际调用，各修改、测试、固定并提交自己的版本。最终验收绑定002的第二个固定交付。正式类别依据是002的本人编辑序号5、同版本测试8与提交13；001的提交也保留在原件中，但没有重新对先前提交执行私有验收。

- **LA r3：** 两成员分别8/7次调用，各自编辑和固定。001在自己版本上执行两次公开测试，最终提交使用后一次同树测试序号12；002先提交、001后提交，最终评估仍只绑定后者的固定版本。

## 类别依据及其限制

r1 保存的五条 Mapper 结果均为 `local_lineage_delivery`。逐条都有：最终固定文件版本 → 可追溯本人生产文件编辑 → 相同版本公开测试 → 测试反馈在最终提交前实际进入本人输入。五个最终交付 `included_patch_ids` 均为空，最终谱系没有伙伴整树采用、未解释的伙伴固定来源取得或 Mapper issues。

该类别只是**最终固定成果的已观察谱系**。它不等于“只有一个人工作”“没有任何协作”“另一成员没有作用”，也不等于正因果贡献或正学习 Contribution。LA r2/LB r2 的跨成员任务创建与认领仍是事实；类别不会删除这些责任事件。两成员都投射同一个已证联合类别，仍只训练各自原输出，不以代码作者或最终提交者筛选目标。

未显式调用 `read_test_result`；Mapper证明原 `run_tests` 返回的当前版本反馈确实出现在提交前实际输入中，不声称读完了完整测试正文或证明理解了它。
