# v229｜在同一个工作现场比较两种组织图

## 本轮要回答的问题

v228.2 的真实 Astropy 异常中，组织策略 Agent 激活了伙伴诊断职责，伙伴也实际开始诊断。正式交接因证据编号的书写格式失败。已在离线副本验证修订后的接口接受有效引用，同时拒绝错误引用。v229 两组都接入这版接口，继续观察模型自己能否完成交接。[上一轮证据](software-benchmark-v228-2-corrected-anomaly.md)

本轮检验一个更具体的问题：同样两个人、同一段工作历史、同样的公开测试，遇到异常后，固定原分工和激活一项局部调整，哪一种能以较少 token 完成正确交付？只有从同一个决策前现场跑出两个真实后果，才有该状态的贡献估计。此前 Astropy 的自主组织组可以自行调整职责，无法替代本轮固定原图的对照臂。

## 如何采到现场并做对照

预定两个开发窗口各 4 个任务身份，独立确认 8 个。题单来自已有运行环境且金补丁／空补丁控制合格的任务。排除原 v228 八题，按固定哈希顺序和仓库覆盖分配，三个阶段身份互斥。部分题在更早的工程实验出现过。开发首窗为 Sphinx-10449、Django-15916、scikit-learn-13496、pytest-5787。[完整题单与顺序](../../artifacts/software-benchmark-v229/design-r1/panel.json)

两名 DeepSeek Flash 非思考模式成员正常修复公开问题。程序分别读取两人的授权视图。某成员首次观察到关联具体工作包的活跃异常时，在操作之间保存代码、职责、两名成员各自的会话与预算。观察范围包含持续修复失败、依赖阻塞、集成冲突或回归、待补验证及交付停滞。当前识别器对部分交付级异常给不出工作包，此类事件缺少可定位的局部变换，保留其观测限制。任务结束或进入最后 4 万 token 时仍无合格现场，按自然运行锁定候选并评分。只有见到真实证据才触发，两名成员的私有历史分别保留。

独立策略 Agent 从该现场可执行的局部变换中提名一项，给出理由和短证据编号。提名先冻结。两个续跑共享这一份提名成本，走相同的受管工具、证据呈现、版本激活、正式提交与官方评分。

| 分支 | 工作成员面对的生效组织图 |
| --- | --- |
| 固定原图 KEEP | 激活当前分工。两位成员继续原来的工作、复核和交付 |
| 执行调整 CHANGE | 激活已冻结且校验合法的局部变换，如交给伙伴独立诊断、指定复核者或转移尚未开工的责任。成员按新权限行动 |

两个分支各自延续到自然结束或预算边界。每条逻辑轨迹上限 500 万输入加输出 token，含共同前缀和提案。物理账单只收一次共同前缀和提案。一次决策后的组织图保持固定，成员可以报告阻塞。两臂都使用已离线验证的诊断交接格式修订。若模型选 KEEP、只存在原图、或提名无效，则仅记录对应状态、按原图结束并评分，不补造调整，也不计为完整配对。

## C/N 怎样起作用

- **贡献 C** 衡量同一现场中某个方案相对当前策略平均值的优势。后继效用等于合法正确交付指示值减去 0.1 倍的逻辑 token 使用比例。代码正确率、正式交付、异常解除和交接回执分别报告。
- **欠覆盖程度 N** 衡量当前策略是否低估了某类合法响应。在同一现场，取参考概率与当前概率之比的正对数。初始 Q0 对两个有效方案各给 50%，所以第一窗口的 N 为 0；从 Q1 起才可能出现正的欠覆盖值。
- 选择器用异常类型、变换种类和已用预算比例表示状态与动作的组合。初始十个系数均为零。两臂全部运行，便于观察每种选择的后果；策略概率用于计算相对贡献、更新下一窗口的选择分布及对冻结确认状态的加权效用。一次参数变化不等于某次具体分工已经执行。
- 同一开发窗口取得四个不同检查点的完整、实质不同的对照才拟合 Q1 或 Q2。较少配对保留逐状态诊断并显示各异常类型样本数，空类单列。确认阶段固定 Q0、Q2，在同一批候选和后果上比较两种策略，无确认成绩反哺。

## 当前工程实验及预算

6 项 CPU 检查通过，包括同接口两臂机制、有效诊断交接、旧权限冲突拒绝、不同检查点或失配变换排除、不完整窗口不拟合、合成两窗口更新和冻结确认，以及完整配对的预约拆分。合成效用只用于验证计算。另将真实 Astropy 决策点映射到新特征，Q0 得到 50%／50%；用旧自主组织对照充作学习样本时被正确排除。此处真实学习样本数为零。[CPU 检查](../../artifacts/software-benchmark-v229/design-r1/cpu-tests.txt) · [历史现场只读对照](../../artifacts/software-benchmark-v229/design-r1/historical-control.json) · [源码冻结](../../artifacts/software-benchmark-v229/design-r1/freeze.json)
