## 2. 本轮修订及明确边界

本轮依据[审计原文](../reference/audit-v023-next-v024.md)与[冻结方案](../domain-collaboration-v024-plan.md)，保留v0.23真实四窗学习、未见完整职责改善以及五个缺失初评。旧结果没有补采、补零或重新评分。

| 审计问题 | 新实现与执行约束 |
|---|---|
| 终局MC将已完成交接的回报广播给后续动作 | 新增实际事件账本；首次合格当前交接结算0.2，终点结算R−0.2，保留负补差及总回报守恒；Handoff-RTG按真实决定序号计算未来回报 |
| 两臂起点和首窗不应混入采样差异 | 本次θ0新采六条共同D0；两个独立owner恢复相同actor、critic、两个optimizer和RNG状态，各消费同一原始D0；原调用、episode、window身份不重写 |
| 后继数据必须来自各自新策略 | 每臂首窗更新后，分别用本臂当前策略采集第二窗；材料和seed相同，真实运行与轨迹独立，不交叉消费 |
| 初评缺失破坏预定比较 | 先完成全部12个初评槽，才允许共同采集和训练；完整指结果已知，不要求成功。结果封存，不据此换题、改LR或挑checkpoint |
| 标识噪声干扰配对 | 预声明确定性可见标识与回执规范化；真实分支、存储、对象、版本、权限及审计身份仍独立；不声称GPU生成逐位确定 |
| 失败与部分终态不能被完整估计覆盖 | 不自动恢复、补采或用第一窗代替第二窗终态；缺失保留null与利用已知端点的兼容界（非置信区间） |
| 外测公开规则与验证指标含混 | 公开实际MISSING处理，分开尝试、执行、表合法、表相等、内容正确、最终声明六项；保持原权限与隔离 |
