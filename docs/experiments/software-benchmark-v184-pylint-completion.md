# v184：原 Pylint 任务的四条件补齐

v183 的新控制已实际通过：同一官方镜像的 gold 为 resolved=true、empty 为 false，两个容器均完成清理。故原问题是隔离见证的 stdout／stderr 混合解析，并非测试无法运行。原 v181 失败控制不改写。

本阶段补齐原题单 Pylint-8898 的 M0、M1-5、M1-10、M3-R 四个尚未调用的身份，不新增题目或模型尝试。其代码生成使用原 v181 SDK 包、任务初态、seed、工具、上下文及每回合 5M。官方评分采用与 v183 合格控制相同的 stdout／stderr 分离入口，参考补丁和官方测试规则不变；用量继续进入原 250 元累计账本。

新普通用户协调器仅在 v181 旧协调器完成清理后启动，并等待 v182 队列到达原 Pylint 任务位置后准入。受修复延后影响，实际开始时间可能晚于相邻任务；报告保留此部署修订和调度差异，不宣称严格同时起跑。v182 的其他任务继续运行，最多四对生成和两路评分使用同一套资源预约槽。

v182 与 v184 各 8 CPU／32 GiB，合计资源上界仍为 48 核等价、296 GiB；不新建系统 slice，不修改共享主机配置。所有对象使用原计划未消费名额，容器 network=none、drop ALL，无宿主绑定、端口或 GPU。只修复评分启动证据的读取，不改变模型看见的测试反馈。
