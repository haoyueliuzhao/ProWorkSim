每root实际执行原始／仅共享侧／仅consumer侧／联合参考四种程序，共20变体。前三种都没有完整通过，联合参考都通过；实际API返回与共享产物消费均有原始证据。仅选与新API相关的pristine上游小回归，不把旧Comparison.right、Schema description或TextFSM List故障继续强加给新消费者。业务有效输入范围、精确结果及必要回归均冻结，参考代码不进入prompt或训练。

## 3. Mapper的有限可判边界

Mapper冻结own_tree_delivery与peer_fixed_product_delivery两类。伙伴类要求可证固定产物进入交付祖先，import元数据和回执实际呈现，至少一个合同生产文件的公开入口规范内容改变且该文件字节连续保留到已测试的固定交付。文件materialized、回执呈现和源码真正进入模型输入分别记录，工具消费不强制逐字读源码。

新增无关helper、纯注释／格式／docstring变化不能制造类别；只比较冻结公开入口的规范AST。这不是旧净AST作者归属，不声称理解或唯一因果价值。动态alias、手工借鉴、部分重写、冲突、覆盖及证据不足保留unmapped；保守未映射不等于没有合作。成员自己的可信原动作继续留在基础损失，不按最终代码署名过滤。

21项针对性CPU控制通过。P1输入核查未重扫；收紧公开入口判别后只读取已绑定初始／最终文件并刷新方法规范，四槽类别未变。

## 4. 原始输入、真实tiny学习与数值继承

旧v029训练验证器只接受原消息子集，与v034合同去重会改变user观察内容这一事实不兼容。新适配器重放同一个冻结Γ作等值核验，训练目标仍只取原input／output IDs和行为概率，不补回已删历史、合同副本或后台通过值。

一次真实tiny CPU控制完成16个极短槽、32次实际自采、64个本人输出token、32个完整反传决定和actor／critic各1步。selected输入确实不是原消息纯子集；行为概率一致，actor分母64、critic分母32，失败与unmapped均保留，v035的共同B权重全1。该控制只执行一次，不是9B资格或实际策略支持。

原tiny控制明确device=cpu，但当时未显式屏蔽CUDA，也未采cuda.is_initialized／GPU资源遥测。因此“GPU模型执行为false”和“CUDA初始化／资源占用未观测”分列，后者为null，不能写成实测0。后续新CPU命令均明确屏蔽CUDA。此边界没有被一次冗余tiny重跑掩盖。

原10份数值实现中9份逐字节保持；online_training.py只增加v035组成验证分派，删除这段声明增量后的全部旧字节与P1冻结版本一致。actor、critic、两个optimizer、数值profile和原3／3 common继续继承，不重做近16K、精度搜索或诊断更新。

另经真实SDK collector→原始导出→Mapper跑过三用途各一条极短CPU控制，共6个合成staff_done响应、零更新。R0／unmapped和本人目标正确保留，训练与开发／确认准入分离。它们是接口控制，绝不进入正式16槽支持。

## 5. 分配绑定与采后冻结

新增桥直接调用已有v030的logN／双锚求解器，区分B、G-raw和I-P，首窗显式h=b；不再套旧v027线性N与共享类别先验。原始分支和类别的全部正负Helmert方向冻结，共同B只一次，C重建后按b中心化。失败、低频、unmapped和未选成员继续权重1，原16槽／成员／本人目标分母不变。未知开发不能填0或静默选权。

5项不同合成CPU控制分阶段覆盖。第一次3过2失败：未知状态触及需要episode路径的深层诊断，以及把浮点相等误当成权重字节相等；仅修相应边界和报告诊断，再复核两个受影响控制。原失败保留，没有宣称首次同源全套通过。详细接口见[分配桥说明](../design/experience-allocation-v035.md)。

采后freezer只读正式P2的原entries／records／实际token绑定／完整common及真实支持，要求监督与worker均可信、原步数未变、当前预算已知，并在任何贡献前生成精确候选清单。它不调用模型、不读取独立结果、不执行训练。共享B真实试训仍须完成当前9B的实际概率／目标消费与完整更新，随后才有更新后贡献开发。

独立只读审查及一个极小CPU编排fixture另验证：n+=6／K=2生成13次唯一试训、52个开发单位，G-raw五个完整方向及I-P一个方向齐全；worker不可信或已有trial路径时拒绝冻结。仅clean-source计划验证和汇总输入使用显式mock，文件／hash／支持／common／方向生成真实执行；这不是实际P2支持或贡献试训。
