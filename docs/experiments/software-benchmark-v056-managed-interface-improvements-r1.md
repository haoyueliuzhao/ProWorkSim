# v056 受管搜索与交付指引修订

日期：2026-10-24。此修订改善未来 PROJECT 的受管接口，当前新实验仍仅运行 Qwen REF，二者独立冻结。没有重写旧运行快照或成绩。

本次增加三项能力：

1. `search_repository` 对成员有权读取的当前源码树做跨文件字面搜索，可选文件／目录前缀。每页最多扫描1,048,576字符、256个条目，返回最多20个匹配，匹配行合计最多8,192字符；空结果页也可能需要继续。字面串跨扫描边界仍能找到，游标绑定成员、查询、前缀和源版本；编辑后旧游标被拒绝。仅搜索UTF-8普通文件，不遍历宿主目录、不跟随链接、不解码二进制。源码快照加载沿用既有受管实现；这里的扫描限额不是对整个加载过程的内存上限承诺。
2. `delivery_status` 以及观察中的同名状态，显示当前准确版本是否有实际公开测试、固定补丁、合法提交及下一项显式操作。它不自动测试、固定或提交，也不提供隐藏验收结果。公开测试失败但确实执行过时，仍可依原规则提交；修改源码立即使旧版本证据不再覆盖当前版本。
3. 仅在最大成员数为1且禁止出生的固定S1条件下，隐藏无伙伴可用的消息、补丁交接及责任转交五个工具。任务板、私有历史和自有补丁合并仍保留；多成员工具定义没有被全局删除。

游标起始页遵循修复后的统一约定：省略、`null`、空字符串均从头开始；非空游标仍严格核对。没有新增不受管bash或任意测试命令，没有放宽文件权限、真实测试要求、测试预算或正式交付标准。

接入使用 `software_benchmark_world_v056.build_software_collaboration_case`，搭配 `software_benchmark_managed_v056.managed_port/build_runtime`。旧v054及其历史快照不会自动切换到该扩展；新PROJECT运行须事前绑定v056接口身份。底层精确候选导出及官方评分继续使用现有文件／版本合同。

必要控制：`tests/test_software_benchmark_world_v056.py` 的4项测试通过，覆盖跨页完整搜索、权限和隐藏材料边界、查询与版本失效、空游标、同版本交付指引及真实HarnessPort接入。Ruff通过。测试使用合成源码与程序化公开测试回调，没有模型、GPU或官方评分调用。
