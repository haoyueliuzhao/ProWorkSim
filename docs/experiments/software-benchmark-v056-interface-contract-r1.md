# PROJECT 工具契约修复 r1

2026-10-24。用户授权按已发现的问题修正环境接口。本修订仅修改当前源码和新增合成控制；旧冻结源码、旧轨迹和评分保持原样，不运行模型或启动 PROJECT 评测。

**修复了什么**

1. `diff_workspace` 的公开参数与执行器统一。v054 执行器已经使用当前工作区版本绑定的 `cursor` 分页，但工具表继承了 v028 的 `offset`、`max_chars`、`source_reference`，使模型按公开说明提供参数也会得到 unexpected keyword。新工具表按当前设计明确只接受可选 `cursor`，每页最多4,096字符；旧三字段不再公布，并在派发前按公开参数规则拒绝，不新增任意版本读取旁路。
2. 仓库导航的首次页写法统一。`list_files`、`read_file`、`search_file`、`read_task`、`diff_workspace` 的可选 `cursor` 允许省略、`null` 或空字符串，三者含义相同；说明明确要求续页原样传回 `next_cursor`。`read_file` 同时给出空 cursor 和 `start_line` 时，仍按首次页的行号定位。
3. 不放宽非空游标。空白字符串、伪造格式、其他操作的游标、编辑前的旧版本游标仍被拒绝。公开测试结果的独立分页协议没有修改。

接口标识更新为 `software-benchmark-world-v056-interface-r1`，避免把本次修复误称为旧实验不变接口。实现仍位于现有 `software_benchmark_world_v054.py`，历史冻结副本不会随当前文件变化。

**权限与语义保持**

差异查看仍只针对当前成员的当前工作区及其冻结基线，遵守真实成员入口检查。不允许通过传入私有 `source_reference` 选择其他工作区；不增加 shell、自动测试、自动固定或自动提交。文件读取、修改、固定产物和官方评分的原有边界保持。

**必要验证**

新增 `tests/test_software_benchmark_interface_contract_v056.py`，4项真实受管 World 合成控制均通过（0.94秒）：

- 公开 diff 参数实际可执行，多页连续覆盖完整差异，页大小有界。
- 五类导航的省略、空字符串、null 游标行为一致；文件行号不被空 cursor 覆盖。
- 跨操作、格式错误及编辑后的旧游标拒绝，拒绝不修改源文件版本。
- 旧未实现参数、伪造私有引用及非执行成员入口拒绝，不再把已声明合法参数派发为 unexpected keyword。
