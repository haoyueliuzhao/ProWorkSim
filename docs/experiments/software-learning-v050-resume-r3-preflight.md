## 真实原件与审查

宿主一次真实派生检查核对r1原1032个源码/材料绑定与r2原1039个绑定同字节，封存r2终态49个文件，确认原16槽不漏不重。计算模块另有一次只读原件派生，两者得到同一预算SHA；没有打开模型tensor载荷或导入真实torch。

两次旧Q−前向1524、反向上界各238、计算区间64586.593825秒；本次额度170001秒，原B实际用量与Q+完整48小时预留合计后，原144小时上界仍有约0.265秒舍入余量。未结束区间的宿主另提前30秒终止回收；系统异常延迟若造成超限仍必须据实报告。不能宣称旧Q−单分支48小时仍成立。

审查期间发现并在模型前修正两项集成问题：新增r1计划引用最初与原容量资格 `original_plan` 字段混淆，现使用独立 `original_r1_plan` 并保留原字段；资源目标最初缺环境、监督状态与派发记录的三方相等检查，现已在CUDA/模型入口前绑定。必要反例覆盖修复，最终只读审查无未解阻断。

单槽拆分的只读源码审查确认原流程本就逐槽设种、独立世界和会话、恢复RNG并检查学习状态。它不证明跨GPU逐token完全一致，也不消除并发改变资源竞争、行政截止和全局暂停在途集合的影响；这些属于本轮已披露资源政策变更。
