## 1 冻结与数据流

1. 保留v196实现及其48点、12题原件，新增v197模块，不热改历史策略。
2. 冻结三档预算、五条件、选择规则、标注标准和一致性门槛。
3. 从v196已核验的真实输入重建可见前缀。被遮蔽观察仍按原位置和消息哈希恢复；新工具不接触未来响应、最终补丁或评分。
4. 输出匿名点位P001至P048及中性候选E001等。供标注的材料没有方法选择、图边、权重或最终结果；完整前缀可查。
5. 两位独立AI审阅者逐点封存，第三位AI审阅者仲裁。标注者通过任务指令和材料目录隔离，没有改动服务器权限或建立新的系统级沙箱；不是人工双盲试验。
6. 查询计算不读取标签；标签齐全后才计算质量指标。所有分歧、源引用和输出保留。

原始Issue的来源另有附录：它最早出现在消息1的完整版本，后来同索引可能是静态字段投影。引用消息1时同时保留原哈希、JSON指针与首次可见步骤，不能把后来的投影误当成原始消息不存在。附录只补来源，没有改动Issue内容或标注结论。

## 2 五条件与关系类型

G0不加历史卡；G1按事件类型与时间；G2使用最近动作的路径焦点和版本约束；G3在同一焦点上使用Confirmed关系；G4增加显式Inferred关系。实体身份、候选池、原文权限和渲染始终相同，避免让图组通过多拿材料取得优势。

| 执行状态 | 允许的关系路径示例 | 证据边界 |
| --- | --- | --- |
| 代码阅读或修改 | contains→calls；imports→depends_on；最长声明路径4条边 | calls确认语法，depends_on仍为推断 |
| 测试执行或报告读取 | tests；tests→contains；tests→contains→calls | 报告位置不等于代码运行覆盖 |
| 版本与产物 | modifies；derived_from；tests | 不利用共享版本节点串联全部历史 |
| 定位 | contains；imports→depends_on；contains→calls | 不默认获得未见仓库内容 |

状态只来自当时已经执行的动作。遍历可以从边的任一端查找证据，但不反转关系的事实含义。`observed_in`、`validates`、`supersedes`不作为相关性扩展捷径。旧版本边不参加当前依赖查询；历史证据可以保留，但必须标为历史版本，不能成为当前测试通过证明。

G3只允许Confirmed；G4中每个Inferred关系有独立标记及折减。来源、权限、版本属于硬约束；相关性和新近性只能在合规候选间排序。

## 3 同预算比较与组件诊断

附加卡片预算为1024、2048、4096个本地估计Token；每卡768、最多8卡，完整输入上限98,304。近期窗口固定为5个完整工具周期。保留当前任务和工作状态；原文回读使用已有接口，剩余输入空间作为恢复余量，没有增加复杂动态预算学习。

四项独立诊断只在4096档执行：

- 移除路径资格筛选和相应直接路径加分，保留其他规则。
- 只移除当前版本的软加分，版本真实性硬约束不动。
- 给G2增加原始任务中的显式路径／符号检索。
- 在同样任务检索上再加入G3的Confirmed关系。

任务检索只查已经观察到、但可能不在当前局部焦点内的实体。它不读完整仓库、调用搜索模型或执行额外工具；因此不能宣称已经实现了对未知代码的主动定位。

事件身份修复作为所有条件的共同基础，不重新制造重复TestRun作为可运行策略。本次诊断不把权限保护或版本证据保护取消后再评算法分数。

## 4 标注与指标

标签为essential、useful、irrelevant、uncertain。必要性针对“在当前问题、近期观察和保留动作基础上，作下一步合理决定还需要的旧证据”；文件重要不等于旧卡必要。没有额外必要旧事件的点允许空集合。

标注另含必要实体、依赖类型与确定性、消息引用、关键失败、缺失证据及覆盖类别。原始依赖允许使用描述性实体，因此不能自动等同于已有图节点。当前只对明确双文件路径做严格可映射诊断，其余符号、版本或多实体关系单列；未通过模糊名称相似度补成“正确匹配”。

必要事件召回只评价默认卡片选择。事件被选中不保证卡片包含全部必要细节，原文引用可读也不等于模型实际读过。证据精确率以必要或有用标签为正；未知标签保留上下界。空必要集合的召回、空选择的精确率记未定义，不自动记100%。

主比较按点汇总，并另报先在任务内平均后的结果。48点来自12题，不按48个独立任务做显著性宣称。主比较预定4096；三档质量成本数据完整保留，不能选最有利预算作为确认结果。

标注一致性门槛在事前固定：必要二分类Cohen κ≥0.60、非空集合平均Jaccard≥0.60、48点双审完成、无未解决的必要项分歧。科学门槛另设：G3比G2必要召回更高，或在不降低召回时减少无关选择；来源与权限错误为0。满足标注门不自动满足科学门。

## 5 历史动态图回放

把已见来源按首次可见步骤重新输入图构建器，不依据最终图直接回答早期问题。500步回放恢复48个历史图，比较完整快照哈希，并检查继续处理新事件后旧快照不变。它验证的是S1的历史事件维护，不声称验证了实际多成员采用、责任转交或角色改变。

合成控制覆盖修改后旧测试失效于当前版本、实际重跑保留新TestRun、新代码可见后增加调用、推断不升级、越权拒绝及图异常回退。局部replace不提供完整代码时，不访问仓库补全AST；后续真正看到的新版本代码才用于建边。
