## 4. 结束原因：context容量与团队token池必须分开

运行器成员终态标签为model_budget_exhausted，但32份预算拒绝的admission_limits均仅为context_capacity，attempt_started=false。具体含义是：选定prompt加固定2048输出预留超过16384容量，不能再进行该次生成。没有一条因团队500000 token用完而闭合。

ST四条均只产生两次真实调用，即两名成员各一次，随后每人一次生成前容量拒绝；另外catalog的两条SB也只有两次真实调用，合计6个槽如此早结束。split条件有更多实际调用，但也全部在容量边界停止。
