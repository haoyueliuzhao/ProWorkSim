# v052 三个未开始槽的 r2 宿主修复

本修复继续执行用户 2026-10-18 的“恢复任务，此外排查异常信号”授权，科学范围沿用 [r1 接续协议](software-bridge-v052-resume-r1-protocol.md)。仍只运行原 xmltodict-1/PS1、xmltodict-2/PS1、xmltodict-2/OH_ref 三槽；seed、先手、raw Qwen3.5-9B、Γ1、数值 provider、初态、工具、容量、预算和验收不变。原四个真实中断槽不恢复、不重采。

## r1 零模型故障保留

r1 的独立用户 service 已正常退出，三个 worker 均以退出码 1 在 `frozen(root)` 校验处停止。失败发生在原 worker 的第一项操作、slot-started 之前，尚未创建任务、resident、SDK、prepared、episode 或模型调用记录。该阶段账本开始/完整调用、token 和预约均为 0；它没有消费三个科学样本，也不产生三个新的科学未知值。

三个 worker 区间分别为 5.018754005432129、5.019733667373657、5.018822431564331 秒，总计 15.057310104370117 秒，作为独立宿主启动成本保留并计一次。原 r1 plan、源码、release、service、trace、日志和停止记录全部封存，不覆写后重新启动其 supervisor。信号日志只记录监督器正常退出，没有新 SIGTERM/SIGINT；本次校验错误必须与原模型阶段的异常信号区分。

## 已证原因与唯一修复

一次两解释器只读探针证实：准备/监督器的 Python 3.14.6 与 native worker 的 Python 3.12.3 对 `ast.dump` 的空字段显示不同。原 r1 plan 与 native 绑定唯一不等项为 `supervisor_AST_sha256`；源码 SHA 和其它全部绑定字段相同。将结构中的 None 和空列表字段统一省略后，两边结构完全一致。因此这是来源测量表示的误拒绝，不是模型代码或任务协议真的改变。

新增独立 `scripts/software_bridge_v052_resume_r2.py`，使用明确版本化的规范 AST 表示计算该元数据；原 r1 模块和原 616 条科学源码保持同字节。不通过切换正式 Python、数值 provider、模型、容量或放宽源码 SHA 来绕开校验。r2 仍在私有 namespace 复用原 worker、ledger 和资源监督器算法，只绑定新宿主入口与确定性的元数据表示。

新释放需另外绑定 r1 零入口审计及跨解释器诊断；如果发现 r1 有任何 slot-started、模型调用、预约或业务活动，就不能按本次零模型修复规则接续。旧九条实际进入记录继续排除，原四条未知及 14,512 不确定预约保持不变。

## 必要控制与实际启动门

仅为本次变化增加跨两个实际解释器的元数据控制及最小零入口反例；原 r1 的三项纯控制、来源资格、初态 SDK/tokenizer、接口和信号控制精确复用，不重跑旧科学资格，也不新增模型资格调用。

root 在独立 release 和修订提交冻结后，准备新根 `runs/software-bridge-v052-resume-r2`。随后以正式 native Python 3.12、CUDA_VISIBLE_DEVICES 为空，调用一次实际 `frozen(root)` 校验完整生产清单；该入口检查不装载权重、不创建 SDK 请求、不分词、不执行业务测试。通过后才启动服务，不用 mock 或准备解释器的结果替代这一必要检查。

宿主继续采用独立 transient user service、Restart=no、supervisor-only strace 且不跟踪 forks，不包装 native worker 或改变其 PID/数值路径。原显存/CPU/磁盘/生成/回合/评分/清理守卫不变，GPU0—7、最多四驻留但库存最多三槽，不增加全局等待超时。

## 预算与收口

仍为原三槽上限 1,500,000 生成 token、384 决定/attempt 和两个 PS1 合计 64 次公开测试。r1 零模型阶段没有可转移的科学预算，原九槽未用预算也不转移。新训练、参数更新、反向及模型资格为零。

收口时仅以 r2 结果替换原报告的三条未开始行，科学库存仍为唯一十二槽；r1 作为零科学样本的宿主启动阶段另列。旧首阶段成本、r1 的 15.057310104370117 秒和 r2 worker 区间各计一次，不增加嵌套耗时。原完整实际费用仍受 14,512 不确定预约限制，不能因 r2 成功而回填。
