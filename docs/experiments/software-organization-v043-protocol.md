# v0.43 分层准入与冻结模型组织开发协议

日期：2026-10-10。依据用户提供的[v0.42审计](../reference/audit-v042-next-v043.md)。用户随审计明确要求“参照审计修订并开展后续实验”，据此授权本轮新协议、catalog四条件首块和有条件的其余12槽。该指令构成新运行的明确确认，不另重复请求；原暂停训练范围不变。

## 1. 保留v042结案，另立新准入

v042原32历史请求复制件及32条CPU程序路线的370阶段全部满足selected硬容量，功能路线全部完成；原资格因1024 token额外工程余量未全满足而`passed=false`。原三个资格文件、源码快照、实验报告和全部org41/org42未启动槽不修改，不填R=0、不改成已完成模型样本。

本轮只调整准入/调度和报告入口，完整沿用v042模型可见Γ：原v041静态去重、3072 Unicode正文页、目录、`read_test_result`工具schema、角色说明、上下文选择、16K/2048和运行时不变。不缩页、不新增去重字段、不改briefing、不扩context、不新设模型资格题，也不重跑不变的CPU世界路线或重新分词来追求全绿。

## 3. 已知风险保留

原CPU历史复制件的1024指标30/32满足；路线资格为核心8/16、原代表10/12、新增组合0/4。32路线370阶段中28阶段工程余量不足。最大selected14333仅剩3 token时，同请求protected11542距硬门2794，说明低selected余量可能来自保留历史。最大protected14284距硬门52、比工程界13312多972，仍有实际后续增长风险。

低余量位置包括shared测试首页、最大文件页、格式反馈/任务增长组合及带4000字符briefing的新生请求。全部风险清单随新准入归档，不删除重形状、不只运行split。真实输出、任务增长、额外错误反馈可能触发硬context；首次真实阻塞保留具体前缀，另轮定向修订，不在本批热改或换seed补采。

## 5. 首块机制门与停止规则

首块只核查新页面协议实际生效、页面/权限/版本/身份正确、已请求反馈是否进入下一真实生成、是否存在明确接口硬容量或关键记录问题。直接worker入口同样验证首块状态和四份测量hash，不可绕过supervisor。

- 仅protected余量不足1024而实际输入可执行：记录诊断，不改变输入、不停止。
- 真实合法反馈后因硬context无法继续：保留正式结果、原前缀和成本，停止其余未启动槽。
- 页面、权限、版本、身份或关键记录异常：阻断对应阶段；可确定结果与技术未知分开。
- 模型不翻页、未读全、不交流、不建任务、不招募或业务失败：不否决后续库存。
- 正常结束、等待无事件或共享预算耗尽：按原工作合同记录，不改称分页故障。
- 首块证据不完整：保持未决，不放行。

不按R、页面数、消息数或人数变化筛选。没有主动翻页和已经请求却无法进入下一次真实输入分开。发现缺陷不热改、不重采，不将历史CPU新生当自然招募。

## 6. 冻结模型、预算与资源

原9B完整common的3/3状态，非共同B后的4/4。参数、精度、温度、原生工具采样和数值路径保持。初始两成员，活动最多4、累计出生最多6；空任务表，无预设岗位、职责或默认经理。允许集中完成及自主组织。

每槽共享128决定、128attempt、500000实际token、32次测试；翻页消耗原决定和token池，不获额外额度，也不增加测试次数。首块上界512attempt、200万token、128测试；全库存2048attempt、800万token、512测试。这些是上界，不能用CPU的370响应估算真实9B耗时。

仅物理GPU3、4、5、7；显存不足等待。沿用单任务时限、显存/活跃剩余显存、CPU RSS、产物与磁盘保护，不恢复撤销的累计GPU/worker/统一墙钟上限，不延续v040额外卡许可。

旧26次Contribution试训、3次正式更新、48条TextFSM确认和梯度缓存生产验证继续暂停。反向及actor/critic参数更新0；原common3/3、共同B4/4及旧双类支持保持历史身份，不与新Γ混用。没有自动旧队列后继。

## 7. 结果、反馈机会与成本

主结果仍为原定义的完整固定交付。成员未提交不补验可变工作区，公开通过不补成隐藏验收通过，读不全不增加Validity惩罚。目录显示失败不等于已见完整expected/observed；实际页呈现不等于理解采用；分享被看到不等于对成功有唯一因果作用。

并列报告：正式R/提交/内容与过程/技术未知、报告保存、目录/页进入哪个成员的真实selected请求、同报告事件/版本历史覆盖并集、后续查询/修改/验证/交接候选与固定交付关系、跨成员实际使用、总调用/页读取/复测/重复读取/token/worker资源。重复页照计成本而内容覆盖不重复；历史覆盖不等于同时可见。未请求、结束、等待、预算、context、故障分别给分母。

每完整root/seed块：信息效应`(PB+PT−SB−ST)/2`，说明效应`(ST+PT−SB−PB)/2`，交互`PT−PB−ST+SB`。任一所需槽未启动或未知则对应主比较保留缺失，不填0、不用已读完或工作更深子集替代。仅两开发root、四配对块，属于固定协议下的条件综合效果，不宣称总体等价、纯信息无成本因果作用或稳定协作优势。

反馈能进入真实输入并支持持续工作后，收口该有限接口修复，转向实际信息使用、内容与交付断点。翻页多/消息多/出生多不自动是能力、有效协作、Contribution或Novelty。新开发轨迹不自动改标训练，不与旧支持拼池；本轮所有条件同样允许增员，不单独识别人数自由度价值。
