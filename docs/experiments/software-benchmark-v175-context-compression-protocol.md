# v175：上下文压缩的离线比较与固定决策点 Replay

日期：2026-11-09。状态与实测结果另见本轮结果报告；本文记录首次付费 Replay 前的设计。

## 1. 本轮回答什么

根据用户提供的 v174 审计，本轮先回答：**真正进入模型输入的内容主要是什么；删除旧观测、抽取保留和混合摘要能否减少输入；省下的输入是否被摘要及回读抵消。**

本轮实施 P0 数据和观测修复，以及 P1 的离线比较、固定决策点 Replay。没有启动新的完整单 Agent 72 回合，也没有启动新一轮多 Agent 通信比较。不改写 v174 的24题成绩，不恢复训练。

用户为本轮新增 API 预算 **250元**，使用独立账本。旧通信试跑99次真实尝试的340,786,705个已知 token、591.85037232元峰值计费上界保持原件。金额只控制新工作准入；已准入工作完成其预留范围，不在途中因全局现金线停止。

## 2. P0 的事实基础与修复

输入数据直接来自 v174 规范72回合的5,523次物理请求，包含61,989个去重消息文本单元和148,830次呈现。数据集保留每次呈现与原请求、来源事件、成员、版本的关联；相同文本在不同请求中出现，分别计入输入。

来源分账使用本地分词估算，不把分片计数伪称 API 精确分账。供应商总账为292,437,574输入、1,209,317输出，合计293,646,891 token。缓存命中已包含于输入。来源分片估算总量286,686,696，其中未归因912,002，占0.3181%；估算口径下 Tool-feedback 占约71.5%，Peer-message 约1.7%。两种总量因模板与分词边界不同不能强行相等。

数据集保存原始文本、来源、接收成员、可核验的来源成员／事件／版本、路径及风险字面标注。后续实际使用证据缺失时记录未知，不以“已发送”“已呈现”代替“已使用”。任务最终结果另存分析标签，不进入 Replay 输入。历史数据已参与开发，不能用作独立确认集。

v174 的155次分片资格失败和4次输出协议拒绝，复用原始机制审计证据：新方案不再强制短消息生成完整 fact-ID 分层结构。此次主要压缩目标改为旧环境观测及历史，而不是假定所有输入都是伙伴通信。

公开测试修复遵循 pytest 插件加载机制：不在 sitecustomize 提前导入 pytest 插件；自有观测插件通过 `PYTEST_DONT_REWRITE` 声明不参与断言重写，保留被测项目的严格警告策略。Flask 原任务镜像、同一初始仓库及同一公开测试命令中，旧入口在收集前失败，新入口59项全部通过。此控制没有应用参考修复或运行隐藏评分，容器已清理。[pytest 插件文档](https://docs.pytest.org/en/7.4.x/how-to/writing_plugins.html)、[断言重写文档](https://docs.pytest.org/en/latest/how-to/assert.html)。

同树交付评分复用改为绑定**这份实际评分请求自己的不可变评分清单**，不再拿准备阶段的另一文件路径作等值条件；候选树、合法交付、实际评分身份及清理检查仍保留。真实入口 CPU 控制覆盖同内容不同清单文件及交付树篡改。修复通过新的部署绑定提供，冻结的旧控制器和历史结果不被热改。

## 3. 方法及与原论文的区别

| 条件 | 本轮实际处理 | 保留内容与限制 |
|---|---|---|
| M0，原输入参照 | 保持捕获的历史消息，不再压缩 | 原输入可能已含旧历史摘要，不能称从起点保留全部轨迹的 Raw Agent |
| M1，旧观测遮蔽 | 将较早环境／工具观测替换为简短引用 | 初始任务、初始观测、助手动作与工具调用身份、最近5个工具返回周期及最新状态保留 |
| M2，抽取保留 | 官方 LLMLingua-2 编码器给旧观测打分，按分数保留约一半旧观测 token 量 | 选择单位为完整观测，代码和 diff 不逐 token 删减；保护区与 M1 相同 |
| M3，混合管理 | 先执行 M1；本地输入超过32,768且存在闭合历史前缀时，最多生成一次摘要 | 最新观测留在前缀外；摘要必须更短才采用；摘要调用及后续回读全部记账 |

M1 借鉴 [The Complexity Trap](https://arxiv.org/abs/2508.21433) 的旧观测遮蔽机制。其公开实现与本项目消息包装不同：本项目除 `role=tool` 外还会用 `role=user` 重复发送 JSON 环境观测。因此正式 r2 同时识别两者，不能只按 OpenAI 消息 role 删除。第一次只遮蔽 tool 消息的离线 r1 保留为准备记录，首次付费调用前已被 r2 取代；48个选点未变。

M2 使用 [LLMLingua-2](https://aclanthology.org/2024.findings-acl.57/) 的实际官方 `microsoft/llmlingua-2-xlm-roberta-large-meetingbank` 权重，版本 `ebaba9b0e874dadd3003ffcff828e4397e568089`。权重经国内 ModelScope 直连取得，其 SHA-256 与官方发布文件一致。没有代理下载、训练或第三方远程模型代码执行。编码器给全部文本分块评分，不截掉超出512 token的后半部分。

M2 是保留概率驱动的**整段抽取适配**，不是原论文逐词删减的完整复现，也没有冒充任务／查询条件化的 LongLLMLingua。每段独立编码，没有新的任务相关性模型。这一限制应结合 Replay 行为变化分析，不能仅用压缩率宣称抽取质量。

M3 的摘要提示初版 G0 在付费调用前冻结。随后允许一次 [ACON](https://arxiv.org/abs/2510.00615v3) 启发的文本 guideline 修订：只用开发分区的 Replay 记录诊断并改写摘要提示，最多2次调用；不更新模型参数，不做压缩器蒸馏。这不是原论文完整长任务优化流程的复现。

## 4. 题单、分区与共同接口

固定24题 C0 历史中的 member_001，每题在输入不超过96,000的 agent 请求序列中选1/3、2/3位置，共48个点。选点仅按预定时序，不按成绩或动作“好坏”。原第一波12题的24点用于开发，原第二波12题的24点作为历史留出；同题不跨分区。

四条件各48点，共192次核心决策 Replay。若 G1 生成成功，再对24个历史留出点做 M3-G1；不将 G1 与 G0 混为一组。历史留出仍不是从未暴露的独立任务集。

四组统一添加只读 `context_read`：只读回该点该成员曾实际看到的原文，单页最多8,192字符，最多2次回读及后续决策。原文身份包含点、回合、成员和内容哈希；不能跨成员读取，也不读当前仓库或改变权限。回读到旧版本不构成当前版本验证。

Replay 使用相同的原工具定义与身份约束。模型提出的原工具动作仅保存，不执行代码编辑、测试、发送消息或提交；唯一实际执行的工具是上述私有原文回读。记录下一步工具、参数、目标文件、可见正文及引用。原历史动作只是行为参照，不是正确答案，也不是判定新动作优劣的评分器。

## 5. 模型、并发和账目

- DeepSeek Flash，非思考，agent `temperature=1`、`top_p=1`；摘要与 guideline `temperature=0.2`。
- 输入98,304、agent 单次输出32,768；摘要／guideline 单次输出2,048。供应商总上下文能力不用于扩大本轮上限。
- 最多32个并行工作。普通用户进程、8核亲和及较低调度优先级；不创建系统资源组、不修改共享服务器配置。编码器短时评分结束即释放 GPU；API Replay 不占 GPU。
- 使用官方固定 HTTPS 端点直连，不使用代理、反向代理、Search／Fetch 或其他联网搜索工具。
- 每个逻辑调用最多3次物理尝试；网络异常独立恢复，物理身份和未知费用保留。单点异常不使整个队列停止。已有可信响应优先复用，不再次发送。
- 每个 Replay 工作开始时预留5元完整有界执行额度；开发 guideline 工作预留2元。预留未用部分随工作结束释放。这是起始准入安排，不是实际预计消费；每工作仍保留5M token 上限。
- 以 API 实际 usage 记录输入、输出、缓存、返回 model/fingerprint；峰值费率输入未命中2元／百万、命中0.04元／百万、输出8元／百万，用于现金上界，不冒充供应商账单或忽略可能的时段折扣。[官方价格](https://api-docs.deepseek.com/zh-cn/quick_start/pricing/)。

每个物理请求保存实际 payload、响应、usage、来源和预留身份。重试未知费用单列，不视为零。旧 v157 账本不写入本轮费用。

## 6. 指标与可支持的结论

主要比较相同点的实际 API 输入与总 token。净输入节省按 `M0 全决策路径输入 − 方法全决策路径输入` 计算；方法路径包含摘要、agent 及所有回读后的请求，不再额外叠加已包含的回读文本。另列摘要输出、agent 输出、开发 guideline 成本、编码器计算时间和峰值显存。

保真指标分层报告：完整原文可恢复率、原路径／版本／测试字面信息在默认视图中的保留、恢复后可用性，以及动作链结构完整性。字面匹配不是语义正确率；版本字面被保留不等于已验证版本正确。摘要中的新增事实需逐例核对，不能用语言模型自评替代事实证据。

行为诊断比较同点 M0、历史动作和压缩后的工具名、完整参数、目标文件及回读。动作不同不能自动解释为错误；动作相同也不能证明任务必然成功。本轮没有产生新的任务完成率、合法交付率或正式非劣效结论。

后续是否进入完整单 Agent 测试，须依据本轮净成本、遗漏和可恢复性证据选择方法，再冻结新的完整运行协议；不能把本轮局部 Replay 的节省比例直接外推到整队或整任务。
