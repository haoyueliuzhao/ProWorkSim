## 本轮实质修订

- O1从空任务表和共同根目标开始，由成员创建、修订、领取、转交和安排依赖；固定patch绑定当时任务版本。公共正常路径、上游回归和自测覆盖分别报告，固定提交与完整验收分开。
- 三个载体的官方原生格式及完整token路径固定。Devstral使用实际v13工具格式与可审计的真实消息envelope；公共SDK保留首次和最新观察及四个完整工具轮。
- 新模型使用自己的LoRA、critic和优化器，不迁移9B适配器；真实资格分别核对推理、概率、完整反向/一步更新、checkpoint重载、新身份回流与近16K容量，诊断后恢复共同起点。
- 一阶分配实现对数N、显式历史锚和覆盖锚；区分不读取类别的G-raw、读取类别先验但类内独立的G-lift辅助对照与类共享I-P，详见[公式边界](../design/experience-allocation-v030.md)。本轮未把它接入真实贡献试训。
