## 2. N：数值问题已缩小到实际执行路径差异

固定原 v0.20.1 的 token、行为概率、actor/profile 身份，阈值仍为最大绝对 logprob 差 ≤0.02、平均差 ≤0.002。

| 路径，相对于原采样 s | 最大差 | 平均差 | 原门 |
|---|---:|---:|---|
| 按原生成约定缓存增量重演，无梯度 | 0 | 0 | 通过所测重演检查 |
| 完整序列、无缓存、无梯度 | 0.0718362331 | 0.00260836235 | 未通过 |
| 完整序列、无缓存、有梯度 | 0.0718362331 | 0.00260836235 | 未通过 |

缓存重演的 146 项 chosen-token logprob 与原记录逐项相同；两条完整前向也逐项相同。两条完整前向各有 6 个 token 的绝对差超过 0.02。这支持在本条固定请求上将后续诊断重心放在缓存增量／完整序列执行差异，而不是继续猜测日志丢失，或把训练模式本身当作已证实根因；不能外推为所有请求都可逐位重演。

实际分支记录：缓存 prefill 进入 24 次卷积整段函数和 24 次 chunk DeltaNet；145 次增量 decode 共进入 3,480 次卷积更新和 3,480 次 recurrent DeltaNet。两条 full 路径各为 24 次整段卷积、24 次 chunk，无 recurrent。记录的是实际进入的 Python 参考函数，不推断未观测的设备 kernel。

预声明位置 0 的 32 层输出在缓存／完整路径间相同。其余预声明增量位置 1、2、31、73、145，以及额外标记的原失败位置 62，最早在 decoder 第 0 块输出已经出现差异；位置 1 第 0 块最大差约 0.0004883，末块最大差 0.5。这一块同时包含多个计算，**不能据此认定 DeltaNet 是唯一或已定位的根因**。观察位置的 full-grad／full-no-grad hidden 差值均为 0。

有梯度前向确实为 train 模式、非重入 checkpoint、零 dropout，输出 `requires_grad=True`；本轮没有 backward，所有参数 `.grad` 仍为空。现有缓存包含原地状态写入，checkpoint 层也会关闭不支持的有状态路径，因此 **no-grad 缓存通过并不建立可用于当前基础损失的缓存训练实现**。不得 detach 过去 LoRA 依赖后将它称为等价训练。

N 正常退出，44.7581 设备秒；三路径的 Torch allocated 峰分别约 20.88、20.64、22.55 GiB。有图前向峰值不等于反向或更新容量。细节、观察位置、实际 dtype/shape 与原证据 SHA 见 [N 专项报告](numeric-paths-v021-results.md)。
