# v203 后续协议：独立失配识别及多文件责任迁移

本协议依据[本轮报告](software-benchmark-v203-dual-graph-report.md)的未通过项制定，状态为准备；不授权新模型调用、训练或旧账本支出。

## 1. 当前实现与缺口

已实现并验证：原受管事件→显式任务／产物／测试映射，完整源码后像哈希恢复，项目状态与组织责任分离，规则化候选和完整迁移包读取门。真实历史材料有12个不同任务、4模式，但没有任务依赖声明和真实责任转交；CPU控制完成一条单文件责任迁移。

尚未实现为生产干预：所有五种操作的完整Harness编译与回滚、多文件必要记忆的逐项恢复、真实组织失配因果判定、完整调用／def-use依赖，以及新的组织下任务效果评测。

## 2. 关系规范

| 关系 | 来源 | 限制 |
| --- | --- | --- |
| owns | 成功claim／accept后的task记录 | 不代表文件独占权 |
| assigned_to | 明确组织指派及task revision | 指派许可不代替实际认领；换revision失效 |
| responsible_for | 显式定义的责任区域及成员集合 | 不从文件修改次数或自由文本自动推断 |
| depends_on | 任务依赖声明或独立可验证结构证据 | import／名称候选保留Inferred |
| crosses_region | 有来源的依赖＋两端当前责任映射 | 任务边界与文件／模块边界要区分 |
| handoff_to | 成功交接回执 | 不代表模型已看到全文 |
| adopts | 成功采用回执及接任者版本 | 不改原作者，不继承其测试结果 |
| validates | 实际执行的TestRun、selector及精确版本 | 不代表整个仓库或官方验收通过 |

每条关系携带来源、版本和有效时间。模型建议、候选组织和组织反馈不能覆盖原始事件。语法范围、语句、作用域、文件的完整性分别保存。

## 3. 失配参考的建设

优先从既有真实任务中获取完整的公开工程材料，由审阅者在不看策略输出和官方终局分数的条件下标注：结构不一致、执行阻塞原因、是否值得干预，以及合法操作集合。按用户此前“你自行审阅”的授权，可做AI工程复核，但必须标为AI参考，不能包装为独立人工金标准。

本轮32场景已用于开发，后续不能再次称独立确认。新的确认参考应与规则开发分开，并记录无法判定项。尤其需要环境故障、正常等待、共同编辑、独立复核这些不应调岗的负例。

预注册筛选门：失配Precision≥0.90、Recall≥0.80，干预Precision≥0.90、Recall≥0.80；同时报告分母、不确定性及未标注比例。阈值不等于已证明统计显著性。不得删除难例或将Unknown强行当负例使指标过门。

## 4. O0–O4正式对照的冻结要求

保留静态固定组织、一次性拓扑映射、动态项目图但固定组织、事件统计调整、项目图驱动调整五条件。首次正式对照仍固定两名成员。

本轮O1只是一次性静态交接控制；进入正式比较前应补全有实质意义的一次性责任映射，包含正确且稳定的初始拓扑例子，而不能只用依赖解除的负例评价它。ToCoMAS式对照需明确适配范围，不称完整论文复现。

各条件相同任务初态、成员能力、工具、可用操作和候选计算上限。分别报告原始候选、规则拒绝、真正执行的调整、真实依赖满足、责任覆盖、负载、独立复核、调整成本与组织震荡。不能只最小化跨成员边，把所有任务压给一人。

最小责任保持窗口、调整后观察窗口、切换上限和成本门需要单独敏感性验证。本轮2步／2次／4抽象成本单位只是CPU机制参数，不直接作为成熟部署设置。

## 5. 状态迁移补充验证

继续使用现有offer／accept、定向消息和原文回读，不新建旁路任务系统。将本轮单文件控制扩展为多文件、不同源版本、多个产物及不同测试范围；必需事实逐项有来源与权限，并区分送达、预览、全文回读、采用与验证。

必须增加：迁移包分页、多次读取才完整、接任者拒绝／超时、旧offer失效、途中版本更新、采用冲突、回滚及再次协商。默认预览不得推动CONTEXT_TRANSFERRED。接任者不免费继承伙伴私有历史；测试只跟随实际执行版本。

还需确认任务owner变化与固定交付人、独立复核职责之间的闭合路径。本轮实际转移没有修改这两项规则，不能依据接任者测试通过自动形成团队合法交付。

## 6. 真实模型阶段

只有独立失配参考、真实合法操作编译及多文件迁移门满足后，才考虑审计提出的8题／32团队回合pilot。该规模目前是候选协议，不是已启动或本轮获准的模型实验。

届时须另行明确预算、冻结任务和源码，保持官方代码正确率与项目合法交付率双端点，统计全队真实输入／输出token、图维护CPU、测试、墙钟、交接回读、返工和未定。被压缩或转交的信息必须绑定实际请求，不能将本轮离线恢复的完整源码算成模型当时已经使用的信息。
