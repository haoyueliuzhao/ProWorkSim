# v177：原文恢复入口的真实模型可用性验证

2026-11-09。用户已明确同意沿用v175账本，累计上限仍250元；开始前已结算21.065782元。此阶段开展12例只读恢复验证，同时准备四组完整单Agent任务协议。

## 为什么增加这一步

v175证明了输入节省，v176证明了原文可按页精确恢复，但此前真实模型未调用过`context_read`。本轮检查模型能否找到入口、读取正确材料、恢复事实，并据此作出一个只读判断。它不执行代码、不运行测试或提交，也不产生新的仓库任务正确率。

## 预选12例

题单从v176实际保留的G0原文档案选取，在首次新调用前固定，不依据本轮模型表现换题。

| 编号 | 要验证的能力 | 原材料 |
|---|---|---|
| r00 | 恢复旧修改动作的精确参数 | pytest历史 |
| r01 | 理解修改被拒绝、没有发生写入 | astropy历史 |
| r02 | 恢复失败测试、异常、版本和计数 | Django历史 |
| r03 | 恢复公开通过结果，区分隐藏验收 | Django历史 |
| r04 | 恢复最后一次修改的版本及完整哈希 | Sphinx历史 |
| r05 | 恢复准确文件路径及修改身份 | SymPy历史 |
| r06 | 区分旧测试版本与最后快照版本 | Django历史 |
| r07 | 区分收集失败与实际执行测试 | Seaborn历史 |
| r08 | 从约第20页位置定向找回最后修改结果 | scikit-learn历史 |
| r09 | 区分零测试与测试通过 | Requests历史 |
| r10 | 将缺失计数保留为未知，不填0 | Requests历史 |

前10例恢复可观测事实，后2例含明确未知控制。模型只获得问题、原摘要及强制原文引用、最后快照的版本身份、统一只读工具和回答格式。评分期望、目标字节范围及隐藏评分均不进入模型请求。

实际使用v176的`HistoryEvidenceStore`：首次读取原文起点可看到消息偏移；后续可按`start`定向读取，单页最多8,192字符。工具说明明确索引用法；对直接观察引用补充原消息编号这一身份元数据。此诊断适配不会向模型注入目标答案或扩大历史可见范围。

## 运行和账目

DeepSeek Flash非思考、temperature=1、top_p=1，最多12并发。每例最多9次逻辑模型请求、8次原文读取；单次输入98,304、输出4,096。每逻辑调用最多3次物理传输尝试；已有成功响应可恢复，单例网络异常不阻塞其他例。

共用`runs/software-benchmark-v175/context-replay-r1/api-ledger.sqlite`，在新增阶段授权表中记录本轮范围；不修改原policy、原请求或原费用。写入前保留旧账本快照，供旧报告的哈希引用追溯。每例开始预留7元完整有界执行额度，未用额度结束释放；这是预留而非预计费用。所有真实usage和未定预约进入原250元累计门。已启动的例子不因全局现金线中断。

普通用户进程、4核亲和、较低优先级，直连官方HTTPS，不经代理，不调用搜索。无Docker、GPU、共享主机配置操作。

## 判定

成功需要同时满足：实际读过目标原文、引用身份正确、指定事实与原件相符、历史／快照／未知范围正确、下一步判断恰当。允许读取同一原始消息的直接观察引用，不强制绕行整段档案；不会因等价恢复路线不同判错。输出格式可以纠正，但不反馈事实答案。

关键事实按原数据类型比较，`false`不能用`0`替代，`null`不能补成0。两项预定未知控制答“未知”是正确行为，不是技术异常。实际读取、事实恢复和判断三个环节分别报告。

12例全部满足才通过本轮功能准入。失败则保留结果、定位原因并修订，不择优拼成12个通过，不据此启动完整压缩任务。即使通过，也只说明这些定向只读任务的可用性，不能证明模型会在真实编码中自主发现每次恢复需求。

## 审计纳入的研究修订

- v175 M2统一称“使用LLMLingua-2编码器评分的观察块筛选”，不称token级LLMLingua-2复现。[原论文](https://aclanthology.org/2024.findings-acl.57/)将压缩建模为token分类；真正token级自然语言压缩及代码、路径、版本等保护留到后续。
- [The Complexity Trap附录E](https://arxiv.org/html/2508.21433v2#A5)确实包含OpenHands v0.43.0、Gemini 2.5 Flash非思考、Verified50题的初步比较：Raw／Masking／Summary完成率40%／30%／42%，平均费用2.39／1.14／1.22美元。因此保留M1-5与M1-10，并重点验证持久摘要，不能只按单步成本选最终方案。
- 该论文正文定义摘要触发量为`N+M`；候选`N=21、M=10`表示累计31轮后摘要前21轮，保留后10轮，不能误写成“第21轮触发”。这里一轮是动作及其观察，不是一个JSON消息。
- [ACON正式会议录](https://proceedings.mlr.press/v306/kang26b.html)为ICML2026。v175仅做一次开发集提示修订，不是完整ACON复现；本轮不做参数训练或压缩器蒸馏。
