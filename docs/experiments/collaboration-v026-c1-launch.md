## 固定执行范围

四个预声明情境 × normal/single_pass 两条件 × 两次固定 seed＝16 槽；两独立 worker 各固定 8 槽，单 world 两角色顺序使用一个共享模型。普通通信与“一次原 demand 原件交接＋正常产物及正式复核流”比较；不是把所有跨成员信息流删除。

从原 v0.25 R1 的完整 actor/critic=3/3 端点恢复。原检查点和 source marker 不改写；核对 17 个数值/模型运行模块的旧新字节一致及完整状态 tensor digest，另记录新载体和 Γ。新增优化器步、训练概率复算和模型 API 调用均为 0。

每 worker 最多 2 GPU 小时，合计最多 4 GPU 小时；单 episode 最多 20 分钟；总墙钟最多 6 小时，包含等卡。资源监测保留停止余量；临时目录位于本项目数据卷，各 worker 独立。既有其他 GPU 作业不被修改或终止。

本记录编写时 8 张 A100 均无所需空闲容量。监督器会按固定上限等卡；没有额度自动扩张、二次尝试、自动恢复或自动后继。排队不是模型运行，未启动槽不记失败零分。实际状态以 `runs/domain-v026-c1/supervisor.json` 和两个 worker 的状态文件为准。
