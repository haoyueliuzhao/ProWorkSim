## 修复了什么

旧 `Session.send()` 不使用普通 Requests 请求读取的 CA 环境变量，本地 HTTPS 服务不能满足其原信任集合；1921 另有本地 HTTP 服务下的 Cookie 过期测试问题。本轮让原客户端经有界 TCP 通道访问真实 `httpbin.org:80/443`，保留原仓库 CA 和 TLS 校验，使用原镜像、官方题目版本和评分器。

连接收尾、连续请求和官方容器清理入口均作了明确适配。客户端重置单独记账；外部连接失败、传输超限或清理未确认仍判为技术未知。两题通过了完整控制，本轮 8 份候选均取得正式报告，未出现技术未知。

这是一次评分环境修复。HTTP 服务与 TLS 路径同时变化，不能把全部改善归因于某一个单独参数；真实公开服务也可能随时间变化，不将本轮与旧环境描述成完全同质的评分批次。
