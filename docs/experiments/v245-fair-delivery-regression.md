# v245：同一交付规则下，允许一次重新分工是否有用？

v244 的三项新增交付说明，OSA 能在中途填补配置缺口。15 题中有 14 题在起点缺少复核人，普通成员又无法补派，因此那三项结果只作为工程机制记录。v245 将任务交付条件和组织策略分开，两个条件共享同一工作环境、权限和校验器。[v244 审计](v244-keep-osa-audit-report.md)

## v245.0　交付规则

普通代码和文档修改由工作包负责人发布确定版本并取得该版本公开测试证据。测试或诊断可以用具名检查范围、真实测试序号、工作版本和结论完成，无需为证据工作额外制造代码改动。组织策略仍可以安排独立诊断与意见交接。任务最终交付需要集成伙伴代码、处理冲突、公开测试最终版本、固定该版本并显式提交。官方评分在模型结束后独立执行。

本轮对风险作了一个可复查的具体定义：两个成员都实际编写了代码时，各作者的代码贡献需要独立复核。两组的工作包负责人都能用同一工具填补该项必需且空缺的责任，复核人须为实际存活的非作者。自审、缺少同版本证据和未解决合并冲突仍会被拒绝。已有完成记录遇到相关文件或元数据变化时，清单会重新列出待办，原记录保留，负责人显式重开后再验证。此规则仅用于新协议。

零 API 验收使用 v244 保存的真实工作区在内存中构造反例。验证了无复核人代码包、无新增补丁的证据包、真实合并冲突、相关版本变化四种情况，并检查了受管补派与禁止自审。证据包反例使用了有真实公开测试回执的诊断／验证路径。[控制回执](../../artifacts/software-benchmark-v245/fair-regression-r1/cpu-controls.json) · [规则实现](../../src/proworksim/software_fair_delivery_v245.py)

## v245.1　六题配对回归

从 v244 的 15 个旧保存点预选六个。覆盖原来实际改组的 pytest-10051、Matplotlib-26113、Sphinx-10449，原两组端点相同且维持分工的 Astropy-13579、Django-11740，以及组织提案被拒的 scikit-learn-9288。结果仅适用于这批已知开发任务。每题从同一原始人员历史和工作树分出两支；共同读取新合同下的当前交付状态。KEEP 维持分工，OSA 额外获得一次组织决策机会。其余条件共用 DeepSeek Flash 非思考模式、两名 Worker、T1、公开测试和官方评分，每支 500 万 token 含共同历史，OSA 调用计入其分支。[冻结题单](../../artifacts/software-benchmark-v245/fair-regression-r1/roster.json) · [输入核验](../../artifacts/software-benchmark-v245/fair-regression-r1/decision-preflight.json)

独立账本 150 元。首批四对按全对最坏价格滚动预约，四对均完成、两类评分齐全、用量对账通过后才开放其余两对。进阶条件不看成绩高低。原 v244 余额属于旧批次。报告同时提供六道相同题的 v244 参照、分组及逐题的代码正确率、正确交付率、完整和新增 token、用时及返工。

## v245.2　自然异常的前瞻性阶段

对象是另行登记、原本就要进行的普通双人任务。被动入口在当前受管任务自然行动后保存现场，排除 v244 的 15 道开发题及其后代。A1 持续失败、A2 上游依赖、A3 集成冲突、A4 验证缺失各最多收取两道不同题，一题只计一次。入组需逐一核对自然行动及付费回执、完整保存点、可执行方案、剩余工作机会和整对现金。只在另有该阶段经费时启动付费分支。暂不开放成员增减，C/N 更新为零。[被动采集入口](../../src/proworksim/software_fair_intake_v245.py)

组织变化按异常依据、组织提案、实际责任、责任人的行动、新成果及采用、同一异常后续证据、最终评分逐项核对。采用率以实际新增成果为分母；额外成果率以实际激活的调整为分母；异常解除率以有可判定后续证据的初始异常为分母，并列出未知数。普通进度检查点没有独立登记的初始异常时，此指标记为不适用。

补充控制使用 Sphinx-9591 的既有搜索回执在新世界类中重放诊断交接。诊断成员引用自己的搜索事件 70 时发出具名结论，无需代码补丁；引用另一成员的事件 69 则被拒。此控制验证诊断职责的证据交接，独立于上面的工作包测试证据完成控制。[搜索证据回放](../../artifacts/software-benchmark-v245/fair-regression-r1/source-only-diagnosis.json)
