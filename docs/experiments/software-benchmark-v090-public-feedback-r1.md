# v090：公开执行反馈与核验提示精简

本修订针对 v089 已记录的重复搜索、重复公开测试、无效测试入口、零测试及管道掩盖退出状态。只实现独立适配和 CPU 控制；没有运行模型、API、GPU 或容器，没有修改正在运行的 v089 或旧冻结源码。真实速度与正确率改善尚未测量。

## 具体改变

| 原问题 | 新反馈 | 保留的边界 |
| --- | --- | --- |
| 相同 grep 连续返回相同内容 | 第二次出现时提示既有请求编号，后续相同情形不反复追加长说明 | 每次原命令照常执行，不阻止复查或缓存替代执行 |
| 相同测试重复运行，或只修改最后的 head/tail | 引用同命令已有的可见测试摘要；简单最终 head/tail 只用于提示比较 | 原命令不改写；输出过滤与不过滤可能影响执行，不能宣称执行等价 |
| 错误模块、收集失败或缺依赖 | 明确“未通过”，建议依据公开仓库核对入口、模块及依赖 | 不自动猜题目文件、改命令或选测试；不访问隐藏材料 |
| Ran 0 tests / collected 0 items / no tests ran | 明确零测试不能证明行为正确，即使 shell=0 或有 OK | 保留原输出及退出码，不把结果改成官方失败或成功 |
| 管道尾端返回 0，但正文 FAILED | 单列正文失败；说明 shell 返回值不能证明测试进程的状态 | 不补造 PIPESTATUS，不将过滤后的缺失日志补成成功 |
| 初始清单、卡住续接、完成自检语义重复 | 缩短附加文字，保留独立预期、聚焦验证、真实结果与未知报告 | 不要求全仓库全部通过，也不以公开测试成功强制结束 |

原生五工具、schema、执行权限、detector、两次 stuck 续接、一次 finish review、累计账本与期限不变。原生 system 本身不改；只替换本项目 v062 附加的三段文字。因此这是新的执行条件，不能热改到旧组后仍称完全相同配置。

## 同版本与回读的准确含义

原生 RPC 默认没有完整的源码版本证明。默认反馈只说“同命令／同可见结果摘要已经出现”，明确不保证源码或运行环境未变。集成方可提供可信 `rpc.public_revision_probe`，只有当前调用前后及上次版本一致时，才显示“同源码版本”；不能从模型参数或模型自述取得该证据。测试有外部状态或随机性时仍可复测。

原生完整输出、已有 saved-output 链接和原始 RPC 逐条保留。`rpc.public_feedback.read_observation(request_id)` 提供可信历史层的精确回读接口，返回副本；它不是新增模型工具，也不会把控制端日志路径伪装成 actor 可读文件。模型直接可用的回读仍是原生历史和原生已保存输出。后续若增加历史投影入口，必须在新运行包中明确接入后再宣称已经可用。

反馈只分析已执行命令的公开正文。对不认识的测试入口或没有明确摘要的输出，记录“无确定摘要”；不据此推断成功。提示引用的是可见报告，既不代替真实测试进程状态，也不代替官方评分。

## 核验与局限

六项必要 CPU 控制最终通过，覆盖：正文失败／零测试／收集错误、重复提示只出现一次、可信版本与版本变化、原生动作仅执行一次且原结果不变、简单输出过滤变体与复杂 shell 反例、原生命周期及问题正文保留。新增过滤变体反例发现事件 `kind` 被状态字段覆盖，已修复并仅重跑该失败项。Ruff 通过。

对 slot325 的 **167 条历史公开 RPC 快照**进行只读回放，共识别导入／收集错误9次、可见失败5次、零测试2次、可见成功5次、没有确定摘要11次，形成7次重复提示。这些是调用级观察分类，可能涉及同题重复，不是任务数、评分或节省调用数；该快照不是完整实验。源码版本证明数为0，因此回放未把任一重复判为已证明同版本。

三段附加提示的字符数分别从 1222→575、809→390、843→347；这是字符统计，不是实测 token、推理耗时或正确率增益。记录及源码指纹见 [CPU 核验与公开回放](../../artifacts/software-benchmark-v090/public-feedback-cpu-r1/summary.json)。

## 新运行包接入接口

`software_benchmark_public_feedback_v090.feedback_rpc_class(NativeToolRPC)` 替代旧反馈 wrapper；每次 `request` 仍只调一次原生 RPC。`software_benchmark_native_control_v090` 导出 `initial_message`、`run_controlled_conversation`、`create_conversation`，其中 conversation 创建路径保留 v057 模型投影和原生工具。截断适配可在同一个 guarded model adapter 的外层独立组合。

此模块只接入原生 RPC 形状。PROJECT 的受管 `run_tests`／`read_test_result` 及正式交付规则没有在本文件内改写；若在新项目运行器接入相同摘要提示，需要继续使用原有真实版本证据和受管回读入口，不添加不受管 shell。启动前应封存新运行包与协议版本，旧记录保留。
