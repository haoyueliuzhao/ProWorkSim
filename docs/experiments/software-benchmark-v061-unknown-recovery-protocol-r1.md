## 已实施及准备中的修复

1. **摘要接口。** 复用已经通过验证的 v056-r2 空工具规范化：无工具的历史摘要请求不发送 `tools=[]` 和对应空工具选择字段；计数、记录与实际请求使用同一规范形式。原有 Agent 工具请求保持不变。
2. **模型启动。** 固定 Python／vLLM 通过私有 ELF loader 以普通用户运行。小型启动器保留 `sys.executable`，使 Python 子进程及 multiprocessing spawn 使用同一解释器；不执行宿主 mount、unshare 或 chroot。CPU 实测固定 Python3.12.3、torch2.13.0+cu130、vLLM0.32.0 可导入，子进程与 spawn 成功，CUDA 尚未初始化。该 CPU 检查不是模型生成数值等价性的证明。
3. **服务生命周期。** 新建仅属于本批的用户级模型单元，最多2个驻留，每个12CPU／96GiB、禁用swap、Restart=no；另有一个4CPU／16GiB的独立调度单元，避免任务依赖交互会话。只按完整归属身份管理这些新单元，不改用户管理器、linger、驱动或现有共享服务。容量不足等待；异常退出保存证据，不能将没有完成回执的进程当作正常结束。
4. **任务隔离。** 求解工具与 SDK 控制器使用两个独立 network=none 容器。每题新建项目专用 Docker named volume：工具容器可读写 `/testbed`，控制器只读相同工作树，从而保留 SDK 实际仓库元数据视图。不绑定现有宿主目录。
5. **模型通道。** 控制器的模型请求通过自身私有 FIFO 和 Docker exec 交给宿主可信进程；宿主仅连接本批的本地模型端口。API key 不进入工具容器，不向 Agent 开放网络，不开放新的容器端口。
6. **候选导出。** 生成关闭、写入者静止、快照、补丁、候选锁分别留存。复用 UTF-8 安全的 Git 二进制补丁路径，验证补丁应用后的文件内容和模式与选定树一致。出现导出中断时，可基于已经固定的同一终态材料恢复，不重选另一个工作区或另一次生成结果。

## 必要运行控制和具体权限范围

新的隔离路径须先通过一个无模型的实际容器诊断，检查原生工具、SDK元数据视图、RPC、文件交接和停止后的导出。为允许处理 CPU 模拟不能覆盖的环境问题，最多预留3组诊断；通过后不重复运行剩余额度，失败记录保留，修订分别封存。任何正式生成一旦进入，均不自动重采。

诊断使用最多4个宿主CPU的亲和范围及16GiB地址空间限制，诊断actor／controller共享该CPU范围；正式运行在两组独立6CPU范围内分配4CPU actor与2CPU controller。这个无模型诊断只验证部署功能，不用于性能比较。诊断容器有180秒内部截止时间；正式生成容器有24000秒内部生命周期上限，模型的21600／23400秒软硬边界从实际进入时计，预留准备与导出收尾空间。内部期限不依赖宿主调度线程存活。

评分容器使用原任务镜像、基线、官方测试和评分规则；新增普通用户 Python 启动与 drop ALL 权限限制。七个任务各执行 gold／empty 控制，分别取得可信环境资格后再评分。共最多14项控制和14项候选评分，评分与新生成异步调度，避免 CPU 测试等待占住所有模型工作机会。

待授权范围为：最多60个新容器（26个正式生成容器、最多6个无模型诊断容器、14个评分环境控制、14个候选评分）和16个新项目专用卷；最多同时2对生成容器和2个评分容器。Actor每个4CPU／16GiB，controller每个2CPU／4GiB，grader每个4CPU／16GiB；全部network=none、drop ALL、no-new-privileges，无GPU设备或宿主绑定目录。每类同时运行数量、总创建次数、精确对象名和归属、清理证明及共享主机容量门都由新派发器检查。

GPU只供本批普通用户的模型服务使用，最多2张，按原至少66,560MiB空闲显存门和GPU UUID租约选择；不要求整卡无人使用，不停止其他使用者的进程。每个模型单元有独立CPU/RAM硬限额，新派发另保留共享主机内存及磁盘余量。仅改变本批的资源调度，不修改数值推理参数。

## 结果与异常处理

逐项保留原结果、新生成／恢复身份、实际账单、候选锁、评分环境及清理证据。可信静止后的局部失败进入异常集合，其他独立任务继续；对象归属、隔离或静止无法证实时停止新增相关资源，不掩盖为模型错误。异常首先归档中断工作树，明确它不是正式最终候选；若归档失败，则保留已经确证停止的本批actor和卷，以便后续恢复证据，并单列 retained_objects。进程已静止与对象已删除分别记账，不将保留对象写成全部清理完成。
