# v088：高编号 FD 修复后的原 API 库存恢复

本次只修复原 API 实验的宿主 I/O、异常作用域与恢复调度。原 DeepSeek 思考模式、REF／PROJECT 各 500 题、5M 输入加输出 token、seed、工具和评分规则不变；总现金仍是原唯一账本的 1500 元。Qwen v084 的驻留和四题队列不在本次操作范围内。

## 停止原因与原记录

v086 的原 slot 5552 在任何模型派发前，宿主模型通信通道抛出 `ValueError: filedescriptor out of range in select()`。随后受信桥初始化失败被原执行器归为共享完整性异常，停止整个 API 队列。提高 `RLIMIT_NOFILE` 并不能改变旧 `select()` 的描述符编号边界；FD 总数也不等于最大编号。

新高 FD 适配器使用 `poll`，保持帧、截止、EOF、读写对象和原网络／CA／TLS限制；新实际 episode 同时绑定该通道及严格局部初始化异常分类。只有可信原件证明零请求、未派发、明确本地 I/O 错误、同任务所有 writer 和资源已清理的情形才独立隔离。账本、权限、候选来源、协议内容及清理未知等共享异常仍保留原停止规则。原 5552 结果及此前技术未知不回写或重跑。

## 恢复与旧交接

准备器首先证明失败 v086 服务已停止、其管理租约已经释放，并逐项核对它所有调度身份的终态和清理证据。新 allowlist 排除任何已有生成记录、旧调度事件、actor/controller/volume 身份、环境目录及 API 请求。仅原来从未消费的身份可获得首次生成。

恢复保留 v086 失败前已经进行的 v085 交接身份：原 stage、gate、inventory-boundary、stopped 及历史文件继续使用 v086 目录，没有重新打开旧派发、复制一份竞争库存或取消旧任务。若旧 owner 仍在运行，其任务保留为外部在途；若交接已经封存，准备直接导入原最终历史，并标记为已经完成导入，避免之后覆盖新补评分。已有 v087 自然预算退出观察器仍可处理原边界。

本次只读库存推演得到 61 个原未消费身份、约 13 个原固定候选待评分。该数量不是另增实验量，正式准备会再次按已封存记录给出精确清单。原账本余额已很少，61 题并不等于预算足以运行或完成 61 题；真实货币准入仍逐请求执行，原 uncertain 预约不释放、不改填零。

所有补评分使用预先固定的原候选与请求。已完成且有可信清理的官方请求只导入原 completion；已开始但没有可信完成证据的请求保留技术未知，不能重放其物理身份。仍由旧 owner 负责的评分不由新队列抢占。新评分线程在父组正常释放后仍可处理固定候选，见下面的权限与资源边界。

## 资源与评分隔离

新普通用户服务为 `proworksim-v088-api.service`，管理 CPU 为 168–175，CPUQuota 800%，MemoryMax 64 GiB、swap 0、NOFILE 16384，继续全局 API48／Qwen4、环境启动16和实际 CPU／内存／磁盘准入。它复用当前 224 GiB API 容器父组，没有创建新的 root 资源组。

新管理服务额外设置 `MemoryHigh=32 GiB`。这是本服务的软节流／回收边界，硬限仍为64 GiB。其目的是让内核回收该服务可回收的缓存，避免已经观察到的“活跃文件缓存使保守工作集门长期暂停”问题；不是全机 drop-cache 或修改共享内存配置。三评分工作线程可以短时超过 high，但可能受到回收和节流，尾延迟／超时概率可能变化，必须保留本部署标签。设置 high 成功不能替代实际准入恢复与运行监测。

生成与 API 请求继续要求父组存在并满足精确资格。官方评分容器原本位于该父组之外，因此新评分 policy 独立检查宿主和自身管理进程压力，并核对同一原授权、任务、候选、CPU、内存、磁盘和 grader 数量。该 policy 明确禁止创建 actor、controller、model 或 volume，仅允许 control／score／delivery_score；不允许通过评分专用入口调用 API。父组在生成全部结束后正常清理，不再自动剥夺既定官方评分的权限。

## 必要验证与部署入口

恢复集成的 9 项 CPU 控制首先通过；随后两项新控制验证准备捕获的旧历史是否已经终结，针对评分权限的一个窄复测核对声明与实际行为一致。共11个不同控制用例，12次执行，定向 Ruff 通过。覆盖真实私有 episode 的高 FD／局部异常绑定、未消费库存互斥、旧在途不重采、清理缺证拒绝、原失败身份匹配、已释放父组下允许固定评分但拒绝生成/API、评分 policy 无法创建未受父组保护的 actor、服务资源边界与旧历史合并。

上述控制没有启动 Docker、模型、外部 API 或服务。高 FD 通道和局部异常分类各自的真实高编号 FD／队列控制另有独立证据，不把这些合成控制当成真实完成率。
