# v132：五种固定组织评测的执行修复与受控交接

本轮修复执行链路，保留原50题、五种组织、DeepSeek Flash非思考模式、团队共享5M token、每组独立100元及原250个任务身份。不会把已调用模型的回合重新采样，也不会用停止后的任意工作树替代事前锁定候选。用户最新要求是：先完成剩余正常任务及其评分，再统一处理历史异常。

## 已确认的问题

| 问题 | 直接证据 | 处理方式与边界 |
|---|---|---|
| 正常生成后的候选导出失败 | 新团队闭合返回`controller_candidate_lock`，宿主正式分支仍索取`project_candidate_lock`；163份结果因此在控制器正常闭合后被标为技术未知 | 新版显式对接字段，双字段冲突时拒绝。历史候选按原锁、来源版本、终态、用量和清理证据恢复派生评分端点，原结果不覆盖 |
| 归档严重变慢 | 协调器匿名内存超过24GiB高水位，内存停顿指标一度约98%；多个回合长期持有完整基线，同时进行大窗口压缩及完整树解析 | 新版固定两个重内存工作线程；模型运行期间只持基线引用，结束后按需加载。同一重阶段包含归档、验证和候选导出，避免48条线程分别积累大对象 |
| 分组调度偏斜 | 旧算法反复计算“已有名额＋剩余份额”，先通过健康门的REVIEW曾取得39/48个名额 | 新版按总容量分配目标份额，在同一调度入口处理真实待运行任务、启动额度及轮转；接通只停止新派发的drain |
| 控制器初始化内存超限 | 21份容器退出证据为OOMKilled／137，与对应团队账本核对均为0次API调用 | 已定位初态审计哈希同时保存所有历史文件的十六进制内容和完整JSON，造成峰值复制。新流式实现必须生成完全相同的旧哈希；历史已消耗物理身份不因此自动重建 |

零模型诊断未覆盖正式候选导出分支，准备期验证因此漏掉了第一项缺陷。新版验证直接执行两个真实原件的正式导出分支，不能只以诊断通过代替正式路径检查。初始化OOM与宿主归档限流是两个不同问题，不能声称提高宿主高水位就修好了容器内OOM。

## 受控停止与数据保留

用户明确批准一次旧协调器SIGTERM、保存中断回合及费用、不强杀、不自动重跑，并允许在模型请求和写入停止后把本批普通用户服务的MemoryHigh从24调整至30GiB，MemoryMax仍为32GiB。第一次工具自动审批在用户明确确认前拒绝了停止，未发出信号；取得确认后，使用pidfd向核实身份的原主进程发送一次SIGTERM，未重复发送。

六个从未进入模型的启动环境仍卡在文件传输或基线快照。用户随后另行允许提前调整高水位；执行前逐项验证这六个身份无模型派发记录、无账本调用，且所有API在途预约为0。原“全部writer已停”证明没有被伪造，例外时序单独记录。调整后待收尾数由40降至17，内存停顿指标降到不足1%，随后旧队列自然结束。

旧队列最终保存201份结果，生成／启动预约为0，协调器释放所有权，未保留其容器或卷。一个真实待补评的`score-9000`预约被交给新生命周期，仅用于保留本批专用资源组并继续这一次尚未创建容器的评分；没有伪造占位对象、重用已评分身份或重新创建系统资源组。

收口时分类如下。这是执行状态，不是模型正确率。

| 原结果类型 | 数量 | 后续口径 |
|---|---:|---|
| 控制器正常闭合，候选锁字段导出失败 | 163 | 必须逐项通过原件校验，才恢复原唯一候选评分 |
| 控制器结果文件缺失 | 21 | 初始化OOM记录保留，不能套用正常候选恢复 |
| RuntimeError | 9 | 独立保留具体原因，不当作正常代码错误 |
| InterruptedError | 7 | 行政停止记录保留，不冒称原会话续接 |
| APIError | 1 | 原费用和不确定预约保留 |

上述分类不意味着所有163份必然可评；恢复器仍会拒绝版本、哈希、用量或清理证据不足的记录。

## 新队列与资源边界

新生命周期沿用同名普通用户协调服务，仍为8 CPU／32GiB硬上限、禁用swap，高水位为已批准的30GiB。原专用容器资源组、1006个容器／251个卷身份总额、48路生成／8路启动／2路评分上限不增加；不改共享挂载、网络、驱动、既有服务或他人对象。模型API仍直连，模型没有联网搜索入口。

新版调度分两个阶段：先完成合格未消费任务及其正常评分，再处理历史异常恢复与补评。原`score-9000`交接预约保留在评分lane0，正常阶段先使用另一路评分；异常阶段消费该原预约后再恢复两路评分。每个异常都有独立状态，不因单题失败取消其他正常任务。

代码端点与项目交付端点继续分开，候选均先锁定再评分；评分不反馈给模型。相同代码／交付树只复用本任务本次候选的结果，不跨组命中旧run ID。
