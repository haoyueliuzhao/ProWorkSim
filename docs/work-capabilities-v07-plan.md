## 结构与边界

1. WorldCore 保持身份、范围、引用、对象、事件和提交职责；Spreadsheet 适配器复用现有限制公式引擎，不引入旧世界子目录。
2. 世界应用显式声明 files/spreadsheets，公开工具定义与实际准入使用相同注册表；未启用能力明确拒绝。没有任意插件加载、GUI、Shell 或全 Excel 承诺。
3. 新对象默认显式发布；历史“写入即发布”作为明确的 implicit_write 政策保留。历史世界/回执不改写；旧 v0.6 使用其冻结运行器，测试旧政策须在新世界明确选择。
4. 正式 release 绑定精确对象版本、发布者、逻辑时间和目标范围；草稿指针与已发布目标分开。current_published 不自动证明领域适用性，fixed 不随新发布失效。
5. 采用声明与提交时采用快照分开；评价读取固定交付/输入版本。提交时已采用但未实际使用、只改标签或错误计算可被独立拒绝，正式批准仍保留。
6. 数值期望来自预声明标量或独立参考；消费中间接口时直接读取其精确不可变版本，不要求 B 获得 A 全部私有上游。
7. 工作人员仅通过公开会话；测量控制器可在事后检查后台。记录当时观察、工具定义、调用和返回，不事后重建成“原观察”。
8. 继续使用单世界单写者和现有文件存储。只新增表格写入、显式发布所需切点；确定性 XLSX 序列化用于相同输入的真实字节比较，不规范化掉错误公式。
9. 后续真实金融工作包通过 observed/reconstructed/synthetic/unknown 接入；没有材料时不制造真实批准或流程历史，本轮不开展采集或专业真实性论证。

## 预先区分的出口

- 工具拒绝：权限、引用、类型或能力不支持；拒绝尝试可有 Q/O 记录，正式对象/发布不产生副作用。
- 合法业务错误：错误公式、未完整交付或陈旧数字可真实落盘/提交，评价必须区别于工具拒绝。
- 信息不足：已配置可请求路线则发请求并等待；未知路线明确返回能力/信息缺口，不靠实验脚本填写隐藏对象 ID 或正确金额。
- 恢复：保留提交前缀、精确文件、发布/授权/采用与真实观察；普通错误与实际进程退出分别报告，不宣称任意故障的恰好一次。

正式报告逐项对应上述要求，保存源提交、摘要、原始目录、开发反例、复验及未执行计数。完成后自动提交推送，不额外要求授权。
