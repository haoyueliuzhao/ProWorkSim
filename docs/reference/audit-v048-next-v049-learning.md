## 四、下一轮方案：一个有界的 E1→E2 真实学习窗口

我建议将下一轮暂记为 **v049**，只做这一主模块：

**Γ1＋严格 O1 稳定两成员 → 新经验采集 → 一个可行组成方向 → 三条匹配真实短更新 → 更新后开发任务。**

### 1. 采用 O1，直接收集自主工作

建议使用两名稳定平等成员，只给共同根目标、公开合同和合法初态。执行任务和职责由模型自己形成，不预置“实现者／复核者”岗位，也不要求最低消息数、多人编辑率或伙伴采用率。集中实现同样是合法结果。

采集使用 **LA/LB 各四次当前策略的新重复，共八槽**：

- LA/LB 明确作为局部训练目标，不称新独立题。
- 同一窗口内策略固定，seed、先手、成员身份和分类规则事前确定。
- 旧 v047/v048 轨迹不拼入新 O1 池。
- 合法失败、未提交、未知和未映射情况都保留，不能只留下成功样本。

### 2. 先看真实支持，再选择一个方向

对每个 root／成员块报告实际重复数、训练资格、Validity、类别数量、各类样本数、有效质量、基础分布 \(b\)，以及实际优势与梯度。

本方案使用“两类各至少两条”作为被探测方向的最低局部支持条件。它只是小窗口的可辨识条件，**不是统计功效保证**。应区分：

- 没有合格支持；
- 只有一个类别；
- 多类但实际梯度相同；
- 名义上不同，但优势或真实优化器使更新差异消失。

如果 I 没有自由度，按原理论取 \(q=b\)。可信基础材料仍可继续 B 更新；不追加采样凑类。与此同时，**I 单类不意味着 G-raw 没有自由度**，因为同一类内可能仍有多条原始轨迹可供重加权。ID_VTDO_实验线路与最终主线_自主组织修订版_20261…

### 3. 从同一完整状态做 B、Q+、Q− 三条真实短更新

按采集前冻结的 root／成员／规范类别顺序，选择第一个有支持、两侧可行、材料上具有非零混合梯度方向的块。选择过程不读取开发结果。

令该块的方向为

\[
d=e_z-b_j,\qquad q_j^+=b_j+\varepsilon d,\qquad q_j^-=b_j-\varepsilon d,
\]

其他块保持基础组成 \(b\)。两侧都满足原单纯形、支持和权重比例界。文件中给出了固定步幅提案：

\[
\varepsilon=\min(0.10,\rho/2),
\]

其中 \(\rho\) 是两侧同时可行的最大半径；实际值由新材料的 \(b\) 和事前绑定的可行域计算，不根据开发成绩调整。

三条分支分别恢复同一完整 \(S_0\)，使用相同材料、优势、mask、batch 顺序和原训练配方：

| 分支 | 唯一组成差别 |
|---|---|
| B | 基础组成 |
| Q+ | 沿所选方向小幅增加 |
| Q− | 沿同一方向小幅减少 |

建议剂量为 **\(H=1\) 个经核实的原 recipe 更新单元**。这不自动等于一次 backward 或一个 optimizer step；学习率、累积、epoch、critic 步骤等要继承实际配方后冻结。

三条更新不相互累积。若实际 Adam/PPO 更新仍将差异压平，就报告这一结果，不临时扩大 \(\varepsilon\)、增加步数或继续搜方向。只输出不同的加权 loss，还不能算完成这一环节。

### 4. 每条更新后状态做四次开发执行

准备 **两个新开发 root，各两个配对 seed**；三条更新后状态分别完成相同四个开发任务，共 12 次执行。

开发材料按来源和派生关系与训练材料隔离。它们目前还没有完成身份绑定，不能把 LA/LB 改名、换 seed 就当成新来源。每个分支在自己的更新后策略下自然组织工作，不复制 B 的任务分工。

=
\frac{\widehat F(Q^+)-\widehat F(Q^-)}{2\varepsilon},
