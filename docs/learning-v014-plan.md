# v0.14 共享模型的有效工作学习与迁移验证

依据 [v0.13审计](reference/learning-audit-v013.md)。基线fd237a3的共享在线工程闭环保留，旧八例只作历史。重点改为工作信号、实际实现/复核、有限规则与信息条件迁移；不重复以两个优化步骤作为主要验收。

## E0：先分离可操作性与信用问题

旧两窗只读信号诊断不做模型回放、不伪造历史分组梯度。新模块在真实更新时记录task/member/过去公共阶段的优势、真实叶梯度、clipping与有界更新后采样概率；保留‘准入、非零信号、实际工作收益’三个层次。

新开发池的两组显式事实×实现/复核/chain共6case，三臂各6episode：full呈现+8192；compact呈现+8192；compact呈现+12288。同一v14工具schema、任务、角色提示、决策上限、初始Qwen和每case抽样seed。第一对仅改变可检索返回呈现，第二对仅改变上下文上限，不把组合效果归因于一个因素。完整合同可用真实inspect(include_contract=true)取回，正文读取不压缩。实际原返回/公开返回/模型输入全部保留。

另做独立四任务开发容量窗（1次更新机会），测模型输入、显存、完整训练耗时与当前概率门。它是容量数据，不是主实验学习结果，不复用其更新后权重或成功轨迹。新Γ尝试FP32/显式KV/efficient attention、matmul high（TF32），沿用0.02/0.002概率阈值。v0.12已有有限high候选证据；本轮仍以当前真实窗口核验。若当前门失败，保留失败，容量另用highest，不放宽门限，也不重跑一套历史精密探针。

CPU路径证据已显示8k会阻断必要raise_issue/approve；三条完整合理路径full/compact最大input+512均<12288。它们是脚本路径的反事实模型请求容量，不是模型成功。正式上下文以覆盖必要公开路径为准，不以模型先成功为学习门槛。

## E1/E2：容量后冻结，固定预算对照

预案为4类任务等份额，每类每窗1个精确ξ×4次新运行，即16episode/窗；两个训练事实组按窗口固定交替，所有条件相同顺序。Mξ=4使两类各2成为可能但不保证；chain三个岗位都真实行动，provider短片段不冒充团队方法支持。每窗重置世界、固定当前权重，窗口后统一更新，下窗由新权重重新采；不把一窗反复训练伪装新交互。

从未训练过本轮素材的同一Qwen基座开始，MC与joint RTG各3个独立训练种子，每个种子内部只有一套共享actor/adapter/optimizer、独立critic。LoRA/学习率/任务份额/所有预算一致，只改变时间信用。早结算仅用于已能判定的真实依据读取/送达，其他复合成果终点结算，失效用终点差额校正；每个ledger总额等于同一终局合同。不新增工具次数奖，不宣称成员token平均目标严格无偏等价。

正式窗口数在容量之后、正式采样之前冻结，从4/6/8中选取满足容量保守外推不超过24 GPU进程小时的最大值（6个训练运行合计，估计用四episode完整容量窗耗时×4×窗口数×6×1.25）。若4窗估计仍超，则据实另写资源决定，不启动名义达标却无法完成的协议。该上限是本轮自主选定的有界开发实验，不把审计建议1536条/条件当授权配额或样本充分性。容量只决定可负担规模/数值profile，不按成功率调整任务份额或补采。

训练中仅在预定节点用开发池冻结检查（具体节点随窗口数写入正式协议），检查后恢复原训练状态，不用开发结果挑checkpoint。最终只评预定末节点；没有改善也按原窗数停止，不追加到幸运成功。每窗一次累积更新，clipping活跃度如实记录；多窗不等于已检验多epoch clipping稳定性。

## 评价与边界

最终冻结评价覆盖新业务事实、交换资料持有者、新计数规则/倍数和真实正确/错误提交，分别报告单岗位和同权重团队。所有内部池仍是同一构造家族，不能宣称独立来源泛化。期间、状态、倍数、去重、订单边界和持有者显式登记，不再用seed奇偶隐含。受控信息对只改变私有规则，在隔离CPU反事实世界检验获取资料前实际输入相同、获取后不同，不当作Qwen迁移证据。

主要结果为依据驱动正确改动、固定版本有据复核、真实错误恢复及完整交付；回报、V、tool成功、梯度和KL诊断分开。旧8例不充当新锁定测试。ID-VTDO只随当前θ/Γ/ξ统计，未有多方法支持就保留基础处理，不启动无支持的O4。已有四项目回接在短工作出现可解释变化后再开展，本轮不重建平台。
