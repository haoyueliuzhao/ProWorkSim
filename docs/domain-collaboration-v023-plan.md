# v0.23：有限Q=B学习与配对工作评价

依据[本轮审计](reference/audit-v022-next-v023.md)和用户“参照审计修订并开展后续实验”的指令，本轮采用72例缩规模研究；这是新协议，不回写尚未执行的144例设计。旧N1/R1/X1结果直接保留，不重做数值候选或桥接验收。

## 研究对象

公共9B基座、fresh LoRA/critic/optimizer；保持v0.20.1存储与采样、v0.22函数式学习路径、native compact、temperature0.7、context16384、output2048、terminal_mc、一次整窗累积和原概率门。compact为固定延用，不称W1胜出。研究只有Q=B，无ID-VTDO组成干预、SFT或教师轨迹。当前clip=0.2不构成更新后策略距离约束。

4个训练窗口，每窗2A+2B+1实现+1复核，合计24训练；同窗A/B各两次为同一精确情境的固定seed重复。另12评价情境（4A/4B/4维护）各两seed，在初态与第4窗后最终状态完全配对，共48评价。一个训练seed，至多4次actor及配套critic更新。零信号真实零步，预定终点不按成绩延长。

角色决策上限恢复完整W1合同：实现12，复核12；A provider6/implementer16；B implementer24/reviewer28。维护沿双角色B上限。业务终止是有限职责期限，不能把监督计算超时当已知零分，也不引入跨片段bootstrap。

新材料先按客户、完整发票和直接派生关系分训练／评价，排除既有v15/v16/v22开发材料；同源新实例不称跨来源泛化。准备质量、顺序及维护的应变／无需改变事前固定；host质量标签不进入观察。程序见证仅检验实际工具、消息、tokenizer及预算下存在完成路线，不进入模型历史、回报或标签。

## 运行与冻结

只有一个共享学习器更新。由于冻结前GPU6/7有评价所需空闲显存，但没有卡满足训练预留，初态评价进程先加载fresh状态，在任何模型生成之前保存公共θ0完整checkpoint；主学习器获得显存后从这个实际θ0恢复，初态外测也绑定它。评价与训练在独立进程中最多两实例并行，评价绝不修改主学习器。评价结果不被训练器读取，不选最佳checkpoint、不改提示/材料/学习率。最终评价只绑定4个窗口全部闭合后明确保存的最终checkpoint。各评价episode保护actor/critic/optimizer/步数及Torch RNG，初末核对同case、seed与业务初态指纹。

各实际模型子进程固定PYTHONHASHSEED=2026093041以约束集合遍历／序列化键序。初末配对的是情境、Torch采样seed与业务初态，不声称全部wire/token输入完全相同。现有StaffRuntime的随机run_id可通过request_key、command_id及工具响应hash进入后续输入；本轮不改世界标识机制，该未控制随机项需随有限重复、单训练seed共同报告，观测差值不作确定性因果归因。更新后固定上下文诊断使用原保存token，另有明确同输入语义。

训练每窗保留全部6个计划槽、成员和本人完整输出token；可信失败仍保留，未知不填零、不重归一分母。诊断按回报分项、角色与真实动作说明正负零优势所强化的行为。每窗最多6个事前指定任务／成员首决策做更新后固定上下文概率变化诊断，不按结果补位，不把正常参数变化要求回到旧行为概率。

内部实验主量为12情境×2重复的完整职责配对变化；同时报告内容、固定交付、复核证据、错误/无据批准、错误问题和缺席。平均部分回报只作辅助。未知导致主点估计不完整，应给已知配对及全分母不确定界。重复不是独立来源，单训练seed不支持稳定性或显著性主张。

外部D2明确修订变体另列3新seed×初末checkpoint=6例；模型adapter与CPU控制就绪才执行，未就绪不阻断内部。grader分数与独立实际协作证据并列，原官方分数不混报。

## 新资源账与停止边界

原v0.22两小时额度已关闭。本轮新上限：内部24GPU小时，其中学习线19小时，初／末评价各2.5小时；外部另2GPU小时，两个checkpoint各1小时。上限包含加载、采样、核查、有图前向、反向、诊断、保存及所有失败／恢复重算，不是完成承诺。至多2个同时模型实例，各自1张A100，主学习器始终单实例。模型网络API调用0。

上一R1仅24决策/3134目标，更新至post边界1478.28秒；完整6例最多172机会，机械同长度推算约2.94GPU小时/窗，4窗约11.77小时，仅作量级参考。真实长请求738.94秒的有图前向＋反向不含no-grad，提示更长和资源竞争都可能提高成本；不承诺72例必在预算内结束。

包括等卡的整轮墙钟上限36小时，超时保留未开始槽；不无限等待。每个业务episode计算监督1200秒；完整更新独立18000秒（5小时）；模型加载900秒，其他边界600秒，停止预留30秒。不能把episode限时用作整个更新窗口限时。host单进程RSS64GiB、同时本项目合计64GiB，新增实验产物24GiB。GPU2–5优先、6备用，其次其他可用卡；只操作本项目进程。训练入场空闲显存至少60GiB，自身采样用量上限56GiB；评价入场至少40GiB，自身上限32GiB。允许与其他项目共享但记录所有同卡进程和利用率；显存不足则等待，不挤占已占显存或停止他人进程。不同卡与资源竞争属于记录条件，不把墙钟时间当GPU总成本。

事前允许全pilot至多一次同窗口恢复，但仅限可证明未到optimizer step的计算中断；原经历/快照/分母与损失完全相同、旧梯度全部丢弃并重算，旧失败计费。概率失败/不可信记录不触发重试；step状态不明停止，不自动重复。无剩余额度则不恢复。阶段失败保留未执行槽与未知，不自动追加窗口或扩大上限。

CPU准备、源冻结、GPU实际运行与最终报告分别记录。初末评价原件在训练完成前不用于人工调参；工作源码和材料在第一条模型采样前统一冻结。
