## 数据保留与校验

每个历史世界单独生成PAX tar＋Zstandard归档。先记录每个文件的大小、mode、UID/GID、纳秒mtime及完整SHA256，再完整解压回读、核对全部成员与内容哈希。只有全部验证通过、原文件身份仍一致、世界锁仍持有，才释放展开副本。异常保留原文件与部分归档，停止后续归档项目。

压缩包、逐文件清单、验证和释放回执保存于已有数据卷的`completed-world-archives-v194/<旧回合标识>/`。原`managed-world/large-snapshots-archive-v194.json`标记提供定位信息。大型原始路径在归档后需先恢复才能按旧路径读取；这不是删除历史内容，也不声称旧分析工具可以直接打开压缩成员。

按需恢复某个成员使用：

```bash
.venv/bin/python tools/archive_completed_worlds_v194.py \
  --restore /完整路径/verified.json \
  --member world/control/versions/对象/版本/member_001.json
```

恢复校验归档及目标文件SHA，只写回缺失的原路径，不覆盖已有文件。完整实验候选、评分和API记录仍保持原路径可读。

4项必要CPU控制通过：完整回读后释放、源文件变更时整批拒绝释放、损坏归档拒绝、越界和共享硬链接拒绝。[校验记录](../../artifacts/software-benchmark-v194/history-archive-cpu-r1/pytest.log)
